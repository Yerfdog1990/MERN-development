    ---> Looping (Iteration): It is a process for executing multiline statement in a single line or repetation of statement 
      -> types of loop 
        1. for loop 
        2. while loop 
        3. do while 

        -> for loop : condition is check at the start , if condition is correct then loop is executed otherwise terminated.(we know about iteration)
           syntax :
              for(initilization; condition ; inc/dec){
                 statement
              }
              eg:
               for(let i=1 ; i<=5 ; i++){
                   console.log(i) // 1 2 3 4 5
               }
               -> factorial 
                  5*4*3*2*1
                  num to 1 (multiply)

            -> while loop : depend on the condition.return boolean , condition is check at the start 
               syntax :
                 while(condition){
                    statement
                 }

            -> do while : condition is check at the end of the loop , so loop is executed at least once , while a condition is correct or not 
              syntax :
                 do{
                    statement;
                 }while(condition)
                 eg:
                 i=1;
                 do{
                    console.log("sumit")
                    i++;
                 }while(i>=10)
