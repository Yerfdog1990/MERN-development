  -> It is maintained by meta (facebook)
  -> With the help of React we can develop SPA (Single Page Application)

  --> Features 
    --> Virtual DOM (speed fast)
    --> Component Based Architecture (reusability)
    --> Support JSX (within javascript we can write HTML)

-> How react application is executed or boot 
  index.html (SPA) 
    <div id="root"></div>
    --> main.jsx (main entry point javascript file)
      -> it get the id root from index.html and render App component (default component) within that div id root.

    --> Components : are the main building block of react application. They are used for reusability. With the help of it we divide our UI into small piecies of code.
       -> types : function and class 
          -> How we create function component 
                 function FunctionName(){
                    //javascript code 
                    return (
                        //html 
                    )
                 }
                 or 
                 const FunctionName=function(){
                     //javascript code 
                    return (
                        //html 
                    )
                 }

                 or 
                 const FunctionName=()=>{
                     //javascript code 
                    return (
                        //html 
                    )
                 }
            eg:
              Home.jsx 
              const Home=()=>{
                 return(
                    <div>
                         <h2> Home Page </h2>
                    </div>
                 )
              }
              export default Home;

              -> use component in another component 
              App.jsx 
              import Home from './Home';

              <Home />

        -> How we render the dynamic data 
           -> expression { }
           eg:
             Home.jsx 
             const title="Home Page";

             <h3> {title} </h3>

        -> How we render array or object 
           map() method of javascript 
           eg:
           Home.jsx 
           const courses=["A","B","C","D"]

            <div>
                <h4> Courses </h4>
                <ul>
                   {courses.map((course,index)=>
                      <li key={index}> {course} </li>
                   )}
                </ul>
            </div>

    -> props (properties): are used to pass data from parent component to child component.Props are read only. Props we can pass as an attribute within a component 
    eg:
       App.jsx 
         const obj={name:'sumit',age:38}
         <About myobj={obj}/>

    -> How we access props in child component 
    About.jsx 
    const About=({myobj})=>{
        <p> {myobj.name} is {myobj.age} year old! </p>
    }

    --> state : are used to manage data within a component. we can change state data as per the requirement. When their is any change in state , it automatically update into UI , without referesh.
       -> to define state we have useState() hook
         syntax :
           const [stateName,updateMethod]=useState(initialValue)
              -> stateName : name of the state 
              -> updateMethod : handler method used to update state value 

              eg:
          const [count,setCount]=useState(0)

    -> Conditional Rendering  
      true/false
        {
            courses.length>0 ? 
              <div> display couses </div> 
              : 
              <div> No course Found </div>
        }
      true
        {courses.length>0  && <div> display courses </div>}

   -> Session 13 
     -> React Hooks : It is a special function that allows us to manage state and other react featutes with in a function components.It introduced in react 16.8 version.
     ** Hooks only use with function component 
        -> Hooks are start with use prefix 
          -> Types of Hooks 
             -> Inbuild Hooks : useState , useEffect , useRef , useMemo , useCallback , useContext etc 
             -> User Define Hooks : created by the user 

      -> useState : this hook is used to manage state within a component. It is mutable (we can change it)
        syntax :
           import {useState} from 'react';

           const [stateName,handleMethod]=useState(initialValue);
             stateName : name of the state 
             handleMethod : method name which is used to update the state value 
         ** when any change in a state data , it automatically updated in the UI , without referesh the whole page

   -> useEffect() :Handles "side effects " like data fetching , subscriptions , manually DOM updation etc. It is used for component life cycle 
      -> Mounting : when a component is load 
          useEffect(()=>{
               
          },[])
      -> Updating : when any change in props or state 
         useEffect(()=>{
               
          },[state|prop])
      -> Unmounting : when we leave from the component (cleaning data)
          useEffect(()=>{

            return ()=>{
               //cleanup data
            }   
          },[])

   -> useRef() : It lets us store a value that persists across renders but doesnot trigger a re-render when it changes. It returns a "ref" object with property current.
       -> Features 
          -> Persistent Storage 
          -> No Re-renders 
          -> Direct DOM Access 

   *** -> Controlled and UnControlled Components 
      -> Controlled Components : React state drives the form data. 
         -> Source of Truth : React State 
         -> Form handling , react validations , dynamic inputs etc 

      -> Uncontrolled Components : DOM handle the form data. (useRef)
        -> Source of Truth : The DOM 
        -> Simple Forms ,
          example : useRef example 
           const inputRef=useRef(null)
           <input type="text" ref={inputRef} />
           
            inputRef.current.value
