## 1. HTML Attributes & DOM Properties

### What are Attributes and Properties?

**Attributes** are defined in HTML markup — they are the key-value pairs you write directly in your HTML tags. They are always strings.

**Properties** are part of the corresponding DOM object generated by the browser from that HTML element. They can be strings, booleans, objects, or any JavaScript type.

```html
<!-- Attributes are what you write in HTML -->
<input type="text" id="username">
```

When the browser loads this HTML, it generates an `HTMLInputElement` DOM object. That object has corresponding **properties**:

```javascript
input.type   // "text"     — property from the type attribute
input.id     // "username" — property from the id attribute
```

### How the Browser Converts Attributes to Properties

1. The browser reads the HTML file
2. For every standard HTML attribute, the browser creates a matching property on the DOM object
3. Non-standard attributes are **not** automatically converted to properties

```html
<input type="text" id="username" secured="true">
```

```javascript
let input = document.querySelector('#username');

console.log(input.type);    // "text"      ← standard attribute → property exists
console.log(input.id);      // "username"  ← standard attribute → property exists
console.log(input.secured); // undefined   ← non-standard → NO property created
```

> **Important:** To access non-standard attributes, you must use `getAttribute()` rather than dot notation on the element.

### Attribute-Property Synchronization

When a **standard attribute** changes, its corresponding DOM property updates automatically — and vice versa. However, there are important exceptions.

**Example 1 — `tabindex` syncs both ways:**

```javascript
let input = document.querySelector('#username');

// Attribute → Property: changing the attribute updates the property
input.setAttribute('tabindex', 2);
console.log(input.tabIndex);  // 2

// Property → Attribute: changing the property updates the attribute
input.tabIndex = 3;
console.log(input.getAttribute('tabindex')); // "3"
```

**Example 2 — `value` only syncs one way:**

```javascript
let input = document.querySelector('#username');

// Attribute → Property: OK
input.setAttribute('value', 'guest');
console.log(input.value);  // "guest"

// Property → Attribute: does NOT sync back
input.value = 'admin';
console.log(input.getAttribute('value')); // still "guest"
```

The `value` attribute stores the **initial/default** value, while the `value` property reflects the **current** value typed by the user.

### DOM Properties Are Typed — Not Always Strings

Attribute values in HTML are **always strings**. But when converted to DOM properties, the type can change:

**Boolean property — `checked`:**

```html
<input type="checkbox" id="chkAccept" checked> Accept
```

```javascript
let checkbox = document.querySelector('#chkAccept');
console.log(checkbox.getAttribute('checked')); // "" (empty string — attribute)
console.log(checkbox.checked);                  // true (boolean — property)
```

**Object property — `style`:**

```html
<input type="password" id="password" style="color:red;width:100%">
```

```javascript
let input = document.querySelector('#password');

let styleAttr = input.getAttribute('style');
console.log(styleAttr);    // "color:red;width:100%" — string

console.dir(input.style);  // CSSStyleDeclaration object — not a string
```

### Custom Data Attributes — `data-*`

To add custom attributes without breaking HTML standards, prefix them with `data-`. All `data-*` attributes are reserved for developer use and will never conflict with standard attributes.

```html
<div id="main" data-progress="pending" data-value="10%"></div>
```

Access them via the `dataset` property:

```javascript
let bar = document.querySelector('#main');
console.log(bar.dataset.progress); // "pending"
console.log(bar.dataset.value);    // "10%"
```

`dataset` returns a `DOMStringMap` — all custom `data-*` attributes are available as properties with the `data-` prefix stripped.

### The `element.attributes` Collection

`element.attributes` returns a live `NamedNodeMap` of all attributes on an element — both standard and non-standard.

```javascript
let input = document.querySelector('#username');

for (let attr of input.attributes) {
    console.log(`${attr.name} = ${attr.value}`);
}
// type = text
// id = username
// secured = true
```

> **Note:** `element.attributes` is a `NamedNodeMap`, not an Array. It does not have Array methods like `forEach()`, `map()`, or `filter()`. Use `Array.from()` to convert it if needed.

## 2. `setAttribute()` — Set Value of an Attribute

### What is it?

`setAttribute()` sets the value of a named attribute on an element. If the attribute already exists, it updates the value. If it does not exist, a new attribute is created. This is the correct way to set both standard and non-standard attributes programmatically.

### How it works

1. You select the target element
2. You call `element.setAttribute(name, value)`
3. If the attribute exists, its value is updated
4. If the attribute does not exist, it is created on the element
5. Attribute names are automatically converted to **lowercase**
6. Attribute values are automatically converted to **strings**

### Syntax

```javascript
element.setAttribute(name, value);
```

| Parameter | Description |
|---|---|
| `name` | The name of the attribute to set. Automatically lowercased on HTML elements |
| `value` | The value to assign. Automatically converted to a string |

**Return value:** `undefined`

### Boolean Attributes — Special Behaviour

Some HTML attributes are **Boolean** — their mere presence means `true`, regardless of their value. To set them to `true`, use `setAttribute()` with any value (even an empty string). To set them to `false`, you must use `removeAttribute()` — you cannot set a Boolean attribute to `false` with `setAttribute()`.

```javascript
// All of these mean disabled = true:
btn.setAttribute('disabled', '');          // empty string
btn.setAttribute('disabled', 'disabled'); // any string
btn.setAttribute('disabled', 'false');    // even "false" — still true!

// The ONLY way to set disabled to false:
btn.removeAttribute('disabled');
```

## 3. `getAttribute()` — Get Value of an Attribute

### What is it?

`getAttribute()` retrieves the current value of a named attribute on an element. It always returns the value as a **string** (or `null` if the attribute does not exist). It is the correct way to read both standard and non-standard attributes, including `data-*` attributes.

### How it works

1. You select the target element
2. You call `element.getAttribute(name)` with the attribute name
3. If the attribute exists, the value is returned as a string
4. If the attribute does not exist, `null` is returned
5. Use `hasAttribute()` first if you need to distinguish between a missing attribute and one with an empty value

### Syntax

```javascript
let value = element.getAttribute(name);
```

| Parameter | Description |
|---|---|
| `name` | The name of the attribute whose value you want to retrieve |

**Return value:** A string with the attribute's value, or `null` if the attribute is not present.

### When to use `getAttribute()` vs dot notation

| Situation | Use |
|---|---|
| Reading a standard attribute's current value | Dot notation: `element.value`, `element.id` |
| Reading a non-standard attribute | `getAttribute('custom-attr')` |
| Reading the original HTML attribute value (not live) | `getAttribute('value')` (vs `element.value` for current) |
| Reading a `data-*` attribute | `getAttribute('data-user')` or `element.dataset.user` |

## 4. `removeAttribute()` — Remove an Attribute

### What is it?

`removeAttribute()` completely removes a named attribute from an element. This is the only correct way to set a Boolean attribute (like `disabled` or `readonly`) to `false` — because setting it to the string `"false"` with `setAttribute()` still leaves the attribute present, which still evaluates as `true`.

### How it works

1. You select the target element
2. You call `element.removeAttribute(name)` with the attribute name
3. If the attribute exists, it is completely removed from the element
4. If the attribute does not exist, `removeAttribute()` silently does nothing — no error is thrown

### Syntax

```javascript
element.removeAttribute(name);
```

| Parameter | Description |
|---|---|
| `name` | The name of the attribute to remove |

**Return value:** `undefined`

### Why you cannot use `setAttribute()` to set Boolean attributes to false

```html
<!-- All three of these produce disabled = true -->
<button disabled>Save Draft</button>
<button disabled="">Save</button>
<button disabled="disabled">Cancel</button>

<!-- And these readonly attributes are all true -->
<input type="text" readonly>
<textarea readonly="">...</textarea>
<textarea readonly="readonly">...</textarea>
```

Setting `setAttribute('disabled', 'false')` does NOT disable = false. The attribute is still present, which means the browser still reads it as `true`. You must call `removeAttribute('disabled')` to truly make it false.

## 5. `hasAttribute()` — Check if an Element has an Attribute

### What is it?

`hasAttribute()` checks whether a specified attribute exists on an element. It returns a boolean — `true` if the attribute is present, `false` if it is not. It is best used before calling `getAttribute()` when you need to distinguish between a missing attribute and one with an empty string value.

### How it works

1. You select the target element
2. You call `element.hasAttribute(name)` with the attribute name
3. Returns `true` if the attribute is present on the element (regardless of value)
4. Returns `false` if the attribute is not present

### Syntax

```javascript
let result = element.hasAttribute(name);
```

| Parameter | Description |
|---|---|
| `name` | The name of the attribute you want to check |

**Return value:** `true` if the attribute exists, `false` otherwise.

### Why use `hasAttribute()` instead of `getAttribute() !== null`?

Both work for checking existence, but `hasAttribute()` is cleaner and more readable. It is also the only way to properly check for Boolean attributes, where the value might be an empty string:

```javascript
// getAttribute returns "" for <button disabled=""> — truthy check fails
if (btn.getAttribute('disabled')) { ... } // "" is falsy — WRONG check

// hasAttribute correctly returns true regardless of value
if (btn.hasAttribute('disabled')) { ... } // true — CORRECT check
```

## 6. Quick Reference Table

### All Attribute Methods at a Glance

| Method / Property | What it does | Returns |
|---|---|---|
| `element.getAttribute(name)` | Gets the value of a named attribute | String or `null` |
| `element.setAttribute(name, value)` | Sets or creates a named attribute | `undefined` |
| `element.removeAttribute(name)` | Completely removes a named attribute | `undefined` |
| `element.hasAttribute(name)` | Checks whether an attribute exists | `true` or `false` |
| `element.attributes` | Returns all attributes as a `NamedNodeMap` | `NamedNodeMap` |
| `element.dataset` | Access `data-*` attributes as object properties | `DOMStringMap` |

### Attributes vs Properties — Key Differences

| | HTML Attribute | DOM Property |
|---|---|---|
| **Where defined** | In HTML markup | On the JS DOM object |
| **Type** | Always a string | String, boolean, object, etc. |
| **Standard only?** | No — can be custom | Only standard attributes |
| **Access method** | `getAttribute()` | Dot notation (`element.value`) |
| **Sync direction** | Attribute → Property (one-way for `value`) | Property → Attribute (most standard ones) |

### Boolean Attribute Rules

| Goal | Correct Method |
|---|---|
| Set Boolean attribute to `true` | `element.setAttribute('disabled', '')` |
| Set Boolean attribute to `false` | `element.removeAttribute('disabled')` |
| Check if Boolean attribute is set | `element.hasAttribute('disabled')` |
| ~~`setAttribute('disabled', 'false')`~~ | Still sets it to `true` — **WRONG** |

### When to Use Each Method

| Scenario | Best Approach |
|---|---|
| Read a standard attribute's live value | Dot notation: `element.value` |
| Read a non-standard or `data-*` attribute | `getAttribute('name')` |
| Add or update any attribute | `setAttribute('name', 'value')` |
| Disable/enable a button | `setAttribute('disabled', '')` / `removeAttribute('disabled')` |
| Check before reading (avoid null errors) | `hasAttribute('name')` then `getAttribute('name')` |
| Access all `data-*` attributes at once | `element.dataset` |
| List every attribute on an element | `element.attributes` (or `Array.from(element.attributes)`) |
