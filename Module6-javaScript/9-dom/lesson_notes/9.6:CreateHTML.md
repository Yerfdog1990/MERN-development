# HTML JavaScript

**HTML JavaScript** refers to the use of JavaScript within an HTML document to create dynamic, interactive, and responsive web pages. While HTML provides the structure and content of a webpage, JavaScript adds behavior and functionality that allows users to interact with the page.

Together, HTML, CSS, and JavaScript form the three core technologies of web development:

* **HTML** provides the structure and content.
* **CSS** controls the appearance and layout.
* **JavaScript** adds interactivity and dynamic behavior.

JavaScript is used by more than 98% of modern websites, making it one of the most important programming languages for web development.

---

# Why Use JavaScript with HTML?

HTML alone creates static web pages.

Example:

```html
<h1>Welcome to My Website</h1>
<button>Click Me</button>
```

The button appears on the page, but clicking it does nothing.

With JavaScript:

```html
<button onclick="alert('Hello!')">
    Click Me
</button>
```

The button now responds when clicked.

JavaScript allows developers to:

* Respond to user actions.
* Validate forms.
* Update content dynamically.
* Create animations.
* Communicate with servers.
* Build web applications.
* Manipulate webpage elements.

---

# How HTML and JavaScript Work Together

When a webpage loads:

1. The browser reads the HTML document.
2. The browser creates the DOM (Document Object Model).
3. JavaScript accesses the DOM.
4. JavaScript modifies page content, styles, and behavior.
5. Users interact with the page.

Example:

```html
<h1 id="title">Hello</h1>
```

JavaScript:

```javascript
document.getElementById("title")
        .textContent = "Welcome";
```

Result:

```text
Hello
```

changes to:

```text
Welcome
```

without reloading the page.

---

# Integrating JavaScript Using the `<script>` Tag

JavaScript is added to an HTML document using the `<script>` element.

The browser executes the code inside the `<script>` tag when it encounters it.

---

## Internal JavaScript

JavaScript can be written directly inside an HTML file.

### Example

```html
<!DOCTYPE html>
<html>
<head>
    <title>Script Tag Example</title>
</head>
<body>

<p>Open the console to see the message.</p>

<script>

console.log(
    "Hello from JavaScript!"
);

</script>

</body>
</html>
```

### Explanation

1. The `<script>` tag contains JavaScript code.
2. `console.log()` outputs a message to the browser console.
3. When the page loads, the message appears in the developer tools console.

Output:

```text
Hello from JavaScript!
```

---

## External JavaScript

JavaScript can also be stored in a separate file.

### index.html

```html
<script src="script.js"></script>
```

### script.js

```javascript
console.log("External JavaScript File");
```

### Advantages

* Better organization.
* Reusable code.
* Easier maintenance.
* Faster page loading through caching.

# The Document Object Model (DOM)

The **Document Object Model (DOM)** is a programming interface that represents an HTML document as a tree structure.

JavaScript uses the DOM to access and manipulate webpage elements.

Consider this HTML:

```html
<html>
<body>

<h1>Hello</h1>

<p>Welcome</p>

</body>
</html>
```

The browser converts it into a tree:

```text
Document
   │
  HTML
   │
 ┌───┴───┐
Head   Body
         │
    ┌────┴────┐
   H1        P
```

JavaScript can navigate this tree and modify any element.

---

# Why is the DOM Important?

The DOM allows JavaScript to:

* Find elements.
* Change content.
* Change styles.
* Add new elements.
* Remove elements.
* Respond to events.
* Create interactive applications.

Example:

```javascript
document.body.style.backgroundColor =
"yellow";
```

This changes the page background color.

---

# Finding HTML Elements

One of the most common tasks in JavaScript is locating HTML elements.

Several DOM methods are available:

| Method                     | Purpose                       |
| -------------------------- | ----------------------------- |
| `getElementById()`         | Select by ID                  |
| `getElementsByTagName()`   | Select by tag                 |
| `getElementsByClassName()` | Select by class               |
| `querySelector()`          | Select first matching element |
| `querySelectorAll()`       | Select all matching elements  |

---

# document.getElementById()

The `getElementById()` method is one of the most frequently used DOM methods.

It selects an element using its unique `id` attribute.

---

## Syntax

```javascript
document.getElementById("elementID");
```

---

## Return Value

Returns:

```text
The HTML element with the specified ID
```

or

```text
null
```

if no matching element exists.

---

## Example: Changing Text Color

```html
<!DOCTYPE html>
<html>
<head>
    <title>JavaScript DOM Example</title>
</head>
<body>

<h1 id="greeting">
    Hello, User!
</h1>

<script>

const heading =
document.getElementById("greeting");

heading.style.color = "green";

</script>

</body>
</html>
```

---

## How It Works

### Step 1

Find the element.

```javascript
document.getElementById("greeting");
```

Returns:

```html
<h1 id="greeting">
    Hello, User!
</h1>
```

---

### Step 2

Store the element.

```javascript
const heading = ...
```

---

### Step 3

Modify the style.

```javascript
heading.style.color =
"green";
```

---

### Result

Before:

```text
Hello, User! (black)
```

After:

```text
Hello, User! (green)
```

---

# document.getElementsByTagName()

This method selects elements based on their HTML tag name.

---

## Syntax

```javascript
document.getElementsByTagName(
    "tagName"
);
```

---

## Return Value

Returns a live:

```text
HTMLCollection
```

containing all matching elements.

---

## Example

```html
<!DOCTYPE html>
<html>

<head>
    <title>HTML JavaScript</title>
</head>

<body>

<h1>GeeksforGeeks</h1>

<h3>HTML JavaScript</h3>

<script>

const h1element =
document.getElementsByTagName(
    "h1"
)[0];

h1element.style.color =
"green";

</script>

</body>
</html>
```

---

## Explanation

### Step 1

Find all `<h1>` elements.

```javascript
document.getElementsByTagName(
    "h1"
);
```

Returns:

```text
HTMLCollection(1)
```

---

### Step 2

Access the first element.

```javascript
[0]
```

because collections use indexing.

---

### Step 3

Modify the style.

```javascript
h1element.style.color =
"green";
```

---

### Result

Before:

```text
GeeksforGeeks (black)
```

After:

```text
GeeksforGeeks (green)
```

---

# Difference Between getElementById() and getElementsByTagName()

| getElementById()     | getElementsByTagName()        |
| -------------------- | ----------------------------- |
| Selects by ID        | Selects by tag name           |
| Returns one element  | Returns a collection          |
| IDs should be unique | Multiple elements allowed     |
| Faster lookup        | May search many elements      |
| Most commonly used   | Useful for groups of elements |

# HTML `<noscript>` Tag

The `<noscript>` element provides alternative content when JavaScript is unavailable.

This happens when:

* JavaScript is disabled.
* The browser does not support JavaScript.
* JavaScript fails to load.

---

## Why Use `<noscript>`?

Without JavaScript, some websites become unusable.

The `<noscript>` tag allows developers to:

* Display warning messages.
* Provide alternative navigation.
* Explain required browser settings.
* Improve accessibility.

---

## Syntax

```html
<noscript>
    Alternative content here
</noscript>
```

---

## Example

```html
<!DOCTYPE html>
<html>

<head>
    <title>HTML JavaScript</title>
</head>

<body>

<h1 id="gfg">
    GeeksforGeeks
</h1>

<h3>
    HTML JavaScript
</h3>

<script>

const h1element =
document.getElementById("gfg");

h1element.style.color =
"green";

</script>

<noscript>

The browser you are using
does not support JavaScript.

</noscript>

<p>

If JavaScript is enabled,
the text inside the
noscript tag will not
appear.

</p>

</body>
</html>
```

---

## How It Works

### If JavaScript is Enabled

The browser executes:

```javascript
h1element.style.color =
"green";
```

The heading becomes green.

The `<noscript>` content is ignored.

Visible output:

```text
GeeksforGeeks
HTML JavaScript

If JavaScript is enabled,
the text inside the noscript
tag will not appear.
```

---

### If JavaScript is Disabled

The browser displays:

```text
The browser you are using
does not support JavaScript.
```

because the `<noscript>` content becomes active.

# Common Uses of JavaScript in HTML

## 1. Form Validation

```javascript
if(username.value === ""){
    alert("Required Field");
}
```

Checks user input before submission.

---

## 2. Dynamic Content Updates

```javascript
element.textContent =
"Updated Content";
```

Changes page content instantly.

---

## 3. Event Handling

```javascript
button.addEventListener(
    "click",
    function(){
        alert("Clicked");
    }
);
```

Responds to user actions.

---

## 4. Animations

```javascript
element.style.left =
"100px";
```

Moves elements dynamically.

---

## 5. API Communication

```javascript
fetch("data.json")
```

Retrieves data from servers.

---

# Best Practices

### Place Scripts Before `</body>`

```html
<body>

...

<script src="script.js"></script>

</body>
```

This allows the page to load before JavaScript executes.

---

### Use External Files

```html
<script src="app.js"></script>
```

for larger projects.

---

### Use Meaningful IDs

```html
<h1 id="mainHeading">
```

instead of:

```html
<h1 id="x1">
```

---

### Avoid Inline JavaScript

Instead of:

```html
<button onclick="myFunction()">
```

prefer:

```javascript
button.addEventListener(
    "click",
    myFunction
);
```

* The `<noscript>` tag provides fallback content when JavaScript is unavailable.

**HTML JavaScript** refers to the integration of JavaScript within HTML documents to create dynamic and interactive web pages. Together, HTML and JavaScript form the foundation of modern client-side web development.
