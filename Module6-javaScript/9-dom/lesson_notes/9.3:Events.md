# JavaScript Events

**JavaScript Events** are actions or occurrences that happen in a web browser and can be detected by JavaScript. Events can be triggered by user interactions such as clicking a button, pressing a key, moving the mouse, submitting a form, or by browser actions such as loading a page or resizing a window.

Events allow web pages to respond dynamically to user actions, making websites interactive and responsive.

---

## Why are Events Important?

Without events, web pages would be static and unable to react to user input. Events enable developers to:

* Respond to button clicks.
* Validate form data.
* Track mouse movement.
* Detect keyboard input.
* Load content dynamically.
* Create interactive user interfaces.
* Improve user experience.

For example, when a user clicks a button, JavaScript can display a message, submit data, or update page content.

---

## Basic Example of a JavaScript Event

```html
<html>
<script>
    function myFun() {
        document.getElementById(
            "gfg").innerHTML = "GeeksforGeeks";
    }
</script>

<body>
    <button onclick="myFun()">Click me</button>
    <p id="gfg"></p>
</body>
</html>
```

### Output

Initially:

```text
Click me

(empty paragraph)
```

After clicking the button:

```text
Click me

GeeksforGeeks
```

### Explanation

1. A button is created using the `<button>` element.
2. The button contains an `onclick` event attribute.
3. When the button is clicked, the `myFun()` function executes.
4. The function selects the paragraph element using `getElementById()`.
5. The `innerHTML` property is updated with the text `"GeeksforGeeks"`.
6. The paragraph content changes dynamically without reloading the page.

# Event Types

JavaScript supports many different types of events. These events are grouped into categories based on their purpose.

---

## 1. Mouse Events

Mouse events occur when a user interacts with an element using a mouse or touchpad.

Common mouse events include:

| Event       | Description                                 |
| ----------- | ------------------------------------------- |
| `click`     | Triggered when an element is clicked        |
| `dblclick`  | Triggered when an element is double-clicked |
| `mousedown` | Occurs when a mouse button is pressed       |
| `mouseup`   | Occurs when a mouse button is released      |
| `mousemove` | Triggered when the mouse moves              |
| `mouseover` | Triggered when the mouse enters an element  |
| `mouseout`  | Triggered when the mouse leaves an element  |

Example:

```javascript
document.addEventListener("mousemove", (e) => {
    console.log(
        `Mouse moved to (${e.clientX}, ${e.clientY})`
    );
});
```

### Explanation

* `mousemove` fires continuously as the cursor moves.
* `clientX` returns the horizontal position.
* `clientY` returns the vertical position.

---

## 2. Keyboard Events

Keyboard events occur when keys are pressed or released.

Common keyboard events include:

| Event      | Description                           |
| ---------- | ------------------------------------- |
| `keydown`  | Fired when a key is pressed           |
| `keypress` | Fired when a character key is pressed |
| `keyup`    | Fired when a key is released          |

Example:

```javascript
document.addEventListener("keydown", (e) => {
    console.log(`Key pressed: ${e.key}`);
});
```

### Explanation

* Every key press triggers the event.
* `e.key` contains the name of the key pressed.

---

## 3. Form Events

Form events occur when users interact with form elements.

| Event    | Description                           |
| -------- | ------------------------------------- |
| `submit` | Triggered when a form is submitted    |
| `change` | Occurs when an input value changes    |
| `focus`  | Triggered when an element gains focus |
| `blur`   | Triggered when an element loses focus |

Example:

```javascript
document.querySelector("input")
        .addEventListener("change", () => {
            console.log("Value changed");
        });
```

---

## 4. Window Events

Window events are triggered by browser actions.

| Event    | Description                              |
| -------- | ---------------------------------------- |
| `load`   | Fired when a page finishes loading       |
| `resize` | Fired when the browser window is resized |
| `scroll` | Triggered when the page is scrolled      |

Example:

```javascript
window.addEventListener("resize", () => {
    console.log("Window resized");
});
```

# JavaScript Event Handlers

An **event handler** is a function that executes when an event occurs.

Event handlers are commonly used for:

* Validating user input.
* Responding to button clicks.
* Loading content dynamically.
* Handling form submissions.
* Displaying notifications.
* Updating webpage content.

Examples include:

* Actions performed when a page loads.
* Actions performed when a page closes.
* Actions triggered when a user clicks a button.
* Validation performed when data is entered.

---

# Event Handling Methods

There are several ways to handle events in JavaScript.

---

## 1. Inline HTML Event Handlers

JavaScript code is written directly inside an HTML attribute.

```html
<button onclick="alert('Button clicked!')">
    Click Me
</button>
```

### Advantages

* Easy for simple examples.

### Disadvantages

* Mixes JavaScript with HTML.
* Difficult to maintain in large applications.

---

## 2. DOM Property Handlers

JavaScript assigns an event handler to an element property.

```javascript
let btn = document.getElementById("myButton");

btn.onclick = () => {
    alert("Button clicked!");
};
```

### Advantages

* Separates JavaScript from HTML.

### Disadvantages

* Only one handler can be assigned at a time.

---

## 3. addEventListener() Method (Recommended)

```javascript
btn.addEventListener("click", () => {
    alert(
        "Button clicked using addEventListener!"
    );
});
```

### Advantages

* Supports multiple listeners.
* Cleaner and more maintainable.
* Allows removal of listeners.
* Supports event capturing and bubbling.

Because of its flexibility, `addEventListener()` is the preferred approach in modern JavaScript.

---

# Event Propagation

When an event occurs, it travels through the DOM in a process called **event propagation**.

There are two phases:

## 1. Capturing Phase

The event moves from the root element toward the target element.

```text
Document
   ↓
HTML
   ↓
Body
   ↓
Div
   ↓
Button
```

---

## 2. Bubbling Phase

The event moves from the target element back up to the root.

```text
Button
   ↑
Div
   ↑
Body
   ↑
HTML
   ↑
Document
```

Example:

```javascript
const button =
document.querySelector("button");

document.querySelector("div")
.addEventListener("click", () => {
    console.log("Div clicked");
}, true);

button.addEventListener("click", (e) => {
    console.log("Button clicked");
    e.stopPropagation();
});
```

### Explanation

* The third parameter `true` enables event capturing.
* Clicking the button triggers the capturing phase first.
* `stopPropagation()` prevents the event from continuing to parent elements.

---

# Event Delegation

**Event Delegation** is a technique where a single event listener is attached to a parent element instead of attaching listeners to multiple child elements.

Example:

```javascript
document.querySelector("ul")
.addEventListener("click", (e) => {

    if (e.target.tagName === "LI") {
        console.log(
            `Clicked on item:
            ${e.target.textContent}`
        );
    }
});
```

### Explanation

1. The listener is attached to the `<ul>` element.
2. When a list item is clicked, the event bubbles up to the parent.
3. `e.target` identifies the clicked element.
4. Only one listener is required regardless of the number of list items.

### Advantages

* Better performance.
* Less memory usage.
* Works with dynamically added elements.

---

# Preventing Default Behavior

Many HTML elements have built-in default actions.

Examples:

* Links navigate to another page.
* Forms submit data.
* Checkboxes toggle their state.

The `preventDefault()` method stops these default actions.

Example:

```javascript
document.querySelector("a")
.addEventListener("click", (e) => {

    e.preventDefault();

    console.log(
        "Link click prevented"
    );
});
```

### Explanation

* Clicking the link normally opens a new page.
* `preventDefault()` cancels the navigation.
* Custom JavaScript behavior can then be executed.

# Practical Applications of JavaScript Events

---

## 1. Form Validation

```html
<html>
<body>

<h2>Form Validation</h2>

<form id="example">
    <input
        type="text"
        placeholder="Enter something"
        id="formInput"
    />

    <button type="submit">
        Submit
    </button>
</form>

<script>
document.querySelector("#example")
.addEventListener("submit", (e) => {

    let input =
    document.querySelector("#formInput");

    if (!input.value) {
        e.preventDefault();
        alert("Input cannot be empty");
    }
});
</script>

</body>
</html>
```

### Explanation

* The `submit` event fires when the form is submitted.
* The input field is checked.
* If empty, submission is stopped using `preventDefault()`.
* An alert message is displayed.

---

## 2. Dynamic Content Creation

```html
<html>
<body>

<h2>Dynamic Content</h2>

<button id="button">
    Add Element
</button>

<script>
document.querySelector("#button")
.addEventListener("click", () => {

    let newDiv =
    document.createElement("div");

    newDiv.textContent =
    "New Element Added";

    newDiv.style.margin = "10px 0";

    document.body.appendChild(newDiv);
});
</script>

</body>
</html>
```

### Explanation

* Clicking the button creates a new `<div>`.
* Text is added to the div.
* The div is inserted into the document.
* New content appears instantly without reloading the page.

---

## 3. Interactive Lists

```html
<html>
<body>

<h2>Interactive Lists</h2>

<ul id="lists">
    <li>Interactive Item 1</li>
    <li>Interactive Item 2</li>
    <li>Interactive Item 3</li>
</ul>

<script>
let ul = document.querySelector("#lists");

ul.addEventListener("click", (e) => {

    if (e.target.tagName === "LI") {
        e.target.style.backgroundColor =
        "yellow";
    }
});
</script>

</body>
</html>
```

### Explanation

* Event delegation is used on the `<ul>` element.
* Clicking a list item triggers the click event.
* The clicked item's background color changes to yellow.
* No separate listeners are needed for each list item.

---

# Key Points

* JavaScript events allow web pages to respond to user and browser actions.
* Events can be triggered by mouse, keyboard, form, and window interactions.
* Event handlers define what happens when an event occurs.
* `addEventListener()` is the recommended method for handling events.
* Event propagation includes capturing and bubbling phases.
* Event delegation improves performance by using a single listener on a parent element.
* `preventDefault()` stops the default behavior of an element.
* Events are essential for creating interactive and dynamic web applications.

## Summary

**JavaScript Events** are the foundation of interactive web development. They allow developers to detect and respond to user actions such as clicks, key presses, form submissions, and mouse movements. By combining event handlers, event delegation, propagation control, and methods like `addEventListener()`, developers can create responsive, efficient, and user-friendly web applications.
