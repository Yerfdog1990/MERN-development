# HTML DOM Location Search Property

The **Location Search Property** in the HTML DOM is used to **retrieve or modify the query string** (also called the search string) of the current URL. The query string is the portion of a URL that appears after the **question mark (`?`)** and is commonly used to pass data between web pages.

The `search` property belongs to the **Location Object**, which contains information about the current URL loaded in the browser window.

## Why is `location.search` Important?

Web developers often use query strings to:

* Pass user information between pages.
* Send search keywords to a server.
* Filter products or records.
* Identify specific resources using IDs.
* Store temporary data in a URL.

For example, in the URL:

```text
https://example.com/products?category=laptops&id=101
```

The query string is:

```text
?category=laptops&id=101
```

Using `location.search`, JavaScript can access this data and use it within the webpage.

---

## Syntax

### Getting the Search Property

```javascript
location.search
```

This returns the query string of the current URL, including the `?` symbol.

### Setting the Search Property

```javascript
location.search = searchString;
```

This updates the query string of the URL and reloads the page with the new search parameters.

---

## Property Value

| Property       | Description                                                                           |
| -------------- | ------------------------------------------------------------------------------------- |
| `searchString` | Specifies the query string to be assigned to the URL. It must include the `?` symbol. |

Example:

```javascript
location.search = "?user=godfrey";
```

---

## Return Value

The `location.search` property returns a **string** representing the query portion of the URL, including the leading `?`.

For example:

```text
https://example.com/index.html?name=John&age=25
```

returns:

```javascript
"?name=John&age=25"
```

---

## Example 1: Display the Search Part of a URL

```html
<!DOCTYPE html>
<html>
<head>
    <title>HTML DOM Location Search Property</title>
</head>
<body>

<h2>HTML DOM Location Search Property</h2>

<button onclick="showSearch()">
    Click Here
</button>

<script>
function showSearch() {
    const url = document.createElement('a');

    url.href =
    "https://www.geeksforgeeks.org/pathname/?course=javascript&id=101";

    alert("URL search value: " + url.search);
}
</script>

</body>
</html>
```

### Output

```text
URL search value:
?course=javascript&id=101
```

### Explanation

1. An anchor (`<a>`) element is created dynamically.
2. The `href` attribute is assigned a URL containing query parameters.
3. The `search` property extracts everything after the `?`.
4. The extracted query string is displayed in an alert box.

---

## Example 2: Getting the Current Page Query String

Suppose the page URL is:

```text
https://example.com/profile.html?username=godfrey
```

JavaScript:

```javascript
document.write(location.search);
```

### Output

```text
?username=godfrey
```

The browser retrieves and displays the search portion of the current URL.

---

## Example 3: Changing the Search String

```javascript
location.search = "?id=500";
```

If the current page is:

```text
https://example.com/index.html
```

the browser navigates to:

```text
https://example.com/index.html?id=500
```

and reloads the page.

---

## Working with Individual Parameters

Since `location.search` returns the entire query string, developers often use the `URLSearchParams` object to extract specific values.

Suppose the URL is:

```text
https://example.com/?name=Godfrey&course=JavaScript
```

JavaScript:

```javascript
const params =
new URLSearchParams(location.search);

console.log(params.get("name"));
console.log(params.get("course"));
```

### Output

```text
Godfrey
JavaScript
```

This allows easy access to individual query parameters.

## Common Uses of `location.search`

### 1. Search Engines

```text
https://google.com/search?q=javascript
```

Query String:

```text
?q=javascript
```

The search term can be accessed using:

```javascript
location.search
```

---

### 2. Product Filtering

```text
https://store.com/products?category=phones
```

The query string tells the website to display only products in the phones category.

---

### 3. User Identification

```text
https://example.com/profile?id=1001
```

The website can retrieve the user's ID using the query string.

---

## Difference Between Location Properties

Assume the URL is:

```text
https://example.com/products/index.html?id=10#reviews
```

| Property            | Value Returned                                          |
| ------------------- | ------------------------------------------------------- |
| `location.href`     | `https://example.com/products/index.html?id=10#reviews` |
| `location.protocol` | `https:`                                                |
| `location.host`     | `example.com`                                           |
| `location.pathname` | `/products/index.html`                                  |
| `location.search`   | `?id=10`                                                |
| `location.hash`     | `#reviews`                                              |

---

## Key Points

* `location.search` returns the query string portion of a URL.
* The returned value always includes the `?` character.
* It can be used to retrieve information passed through URL parameters.
* Assigning a value to `location.search` changes the URL and reloads the page.
* It is commonly used in search pages, filtering systems, and dynamic web applications.
* The `URLSearchParams` object can be used with `location.search` to easily access individual query parameters.

### Summary

The **HTML DOM Location Search Property** provides a simple way to access and manipulate the query string of a URL. It is widely used in web development to pass data between pages, perform searches, filter content, and create dynamic user experiences based on URL parameters.
