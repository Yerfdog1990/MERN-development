# Polyfills in JavaScript

---

## What is a Polyfill?

A **polyfill** is a piece of JavaScript code that provides modern functionality in older browsers that don't natively support it.

When a programming language evolves, new built-in methods get added — like `map`, `filter`, `reduce`, `flat`, `call`, `apply`, `bind`. Older browsers that existed before these methods were introduced cannot use them. A polyfill is your own custom implementation of that method, written as a fallback so the code works everywhere.

> **In short:** A polyfill is your own version of a built-in method — the same behaviour, implemented manually.

---

## How Polyfills Work — `Array.prototype`

Array methods like `map`, `filter`, and `reduce` live on `Array.prototype`. When you call `arr.map(...)`, JavaScript looks up the prototype chain to find the `map` method there.

You can verify this in the browser console:

```js
const arr = [1, 2, 3];
console.log(arr); // expand the __proto__ to see map, filter, reduce, flat...
```

To add your own polyfill, you attach a method to `Array.prototype` under a new name:

```js
Array.prototype.myMap = function(callback) {
  // your implementation
};
```

Now every array in your code has access to `.myMap()`.

## Polyfill for `Array.prototype.map()`

### How `map()` Works

`map()` iterates over every element in an array, calls a callback on each one, and returns a **new array** of the results — without modifying the original.

```js
const arr = [1, 2, 3, 4, 5];
const squared = arr.map((num) => num * num);
console.log(squared); // [1, 4, 9, 16, 25]
```

The callback receives three arguments: `(element, index, array)`.

### Implementing `myMap`

```js
Array.prototype.myMap = function (callback) {
  // Edge case: this must be an array
  if (!Array.isArray(this)) {
    throw new TypeError('myMap must be called on an array');
  }

  // Edge case: callback must be a function
  if (typeof callback !== 'function') {
    throw new TypeError(callback + ' is not a function');
  }

  // Edge case: empty array — return empty array immediately
  if (this.length === 0) return [];

  const result = [];

  for (let i = 0; i < this.length; i++) {
    // 'this' refers to the array calling myMap
    // pass element, index, and the original array to the callback
    result.push(callback(this[i], i, this));
  }

  return result;
};

// Usage
const arr = [1, 2, 3, 4, 5];
const squared = arr.myMap((num) => num * num);
console.log(squared); // [1, 4, 9, 16, 25]

const doubled = arr.myMap((num) => num * 2);
console.log(doubled); // [2, 4, 6, 8, 10]
```

**Why `this`?** When you call `arr.myMap(...)`, `arr` is the object executing the method. Inside the method, `this` refers to `arr` — so `this.length` is the array length, and `this[i]` is each element.

**Key points:**
- Returns a **new array** — never modifies the original
- Calls the callback with `(element, index, originalArray)` — matching native `map()` behaviour
- Validates that the callback is a function before proceeding

## Polyfill for `Array.prototype.filter()`

### How `filter()` Works

`filter()` iterates over an array, calls a callback on each element, and returns a **new array** containing only the elements for which the callback returned `true`.

```js
const arr = [1, 2, 3, 4, 5, 6];
const evens = arr.filter((num) => num % 2 === 0);
console.log(evens); // [2, 4, 6]
```

The callback must return a **boolean value** — `true` to keep the element, `false` to exclude it.

### Implementing `myFilter`

```js
Array.prototype.myFilter = function (callback) {
  // Edge case: this must be an array
  if (!Array.isArray(this)) {
    throw new TypeError('myFilter must be called on an array');
  }

  // Edge case: callback must be a function
  if (typeof callback !== 'function') {
    throw new TypeError(callback + ' is not a function');
  }

  // Edge case: empty array — return empty array immediately
  if (this.length === 0) return [];

  const result = [];

  for (let i = 0; i < this.length; i++) {
    // callback.call() passes element, index, and original array
    // just like the native filter() does
    if (callback.call(this, this[i], i, this)) {
      result.push(this[i]);
    }
  }

  return result;
};

// Usage
const arr = [1, 2, 3, 4, 5, 6];

const evens = arr.myFilter((num) => num % 2 === 0);
console.log(evens); // [2, 4, 6]

const greaterThanThree = arr.myFilter((num) => num > 3);
console.log(greaterThanThree); // [4, 5, 6]
```

**How it works:**
1. Loop over the array with `this`
2. Call the callback with the current element — the callback returns `true` or `false`
3. If `true`, push the element into the result array
4. Return the result array — original is untouched

## Polyfill for `Array.prototype.reduce()`

### How `reduce()` Works

`reduce()` processes an array from left to right, accumulating all values into a **single final result**. That's why it's called reduce — many values reduce down to one.

```js
const arr = [1, 2, 3, 4, 5];
const sum = arr.reduce((acc, curr) => acc + curr, 0);
console.log(sum); // 15
```

The callback receives `(accumulator, currentValue, index, array)`.

**The initial value is optional:**
- If provided → accumulator starts at `initialValue`, iteration starts at index `0`
- If not provided → accumulator starts at the first element, iteration starts at index `1`

```js
// With initial value (acc = 0 to start)
arr.reduce((acc, curr) => acc + curr, 0); // 15

// Without initial value (acc = 1 to start)
arr.reduce((acc, curr) => acc + curr); // 15 (same result here, but behaviour differs)
```

### Implementing `myReduce`

```js
Array.prototype.myReduce = function (callback, initialValue) {
  // Edge case: this must be an array
  if (!Array.isArray(this)) {
    throw new TypeError('myReduce must be called on an array');
  }

  // Edge case: callback must be a function
  if (typeof callback !== 'function') {
    throw new TypeError(callback + ' is not a function');
  }

  // Edge case: empty array with no initial value
  if (this.length === 0 && initialValue === undefined) {
    throw new TypeError('Reduce of empty array with no initial value');
  }

  // Edge case: single element with no initial value — return that element
  if (this.length === 1 && initialValue === undefined) {
    return this[0];
  }

  let acc;
  let startIndex;

  if (initialValue !== undefined) {
    acc = initialValue;   // accumulator = initial value
    startIndex = 0;       // start iterating from index 0
  } else {
    acc = this[0];        // accumulator = first element
    startIndex = 1;       // start iterating from index 1
  }

  for (let i = startIndex; i < this.length; i++) {
    // pass accumulator, current element, index, and original array
    acc = callback.call(this, acc, this[i], i, this);
  }

  return acc;
};

// Usage
const arr = [1, 2, 3, 4, 5];

function getSum(acc, curr) {
  return acc + curr;
}

const sum = arr.myReduce(getSum, 0);
console.log(sum); // 15

const product = arr.myReduce((acc, curr) => acc * curr);
console.log(product); // 120
```

**Step-by-step trace (no initial value):**

```
arr = [1, 2, 3, 4, 5]
acc = 1  (first element)
i = 1: acc = 1 + 2 = 3
i = 2: acc = 3 + 3 = 6
i = 3: acc = 6 + 4 = 10
i = 4: acc = 10 + 5 = 15
return 15
```

## Polyfill for `Array.prototype.flat()`

### How `flat()` Works

`flat()` flattens nested arrays into a single array. The `depth` argument controls how many levels of nesting to remove.

```js
const arr = [1, 2, 3, 4, [5, 6], [[7, 8]]];

arr.flat();          // [1, 2, 3, 4, 5, 6, [7, 8]]  — default depth 1
arr.flat(2);         // [1, 2, 3, 4, 5, 6, 7, 8]    — depth 2
arr.flat(Infinity);  // [1, 2, 3, 4, 5, 6, 7, 8]    — all levels
```

### Implementing `myFlat`

The key technique is **recursion** — when an element is itself an array, call the function again on that nested array with a decremented depth.

```js
Array.prototype.myFlat = function (depth = 1) {
  // Edge case: this must be an array
  if (!Array.isArray(this)) {
    throw new TypeError('myFlat must be called on an array');
  }

  // Edge case: depth must be a non-negative number
  if (typeof depth !== 'number' || depth < 0) {
    throw new RangeError('depth must be a non-negative number');
  }

  // Edge case: depth 0 — return a shallow copy, no flattening
  if (depth === 0) return [...this];

  // Edge case: empty array
  if (this.length === 0) return [];

  const tempArray = [];

  function getFlattenedArray(array, depth) {
    for (let element of array) {
      if (Array.isArray(element) && depth > 0) {
        // element is a nested array — recurse with depth - 1
        getFlattenedArray(element, depth - 1);
      } else {
        // element is not an array (or depth reached) — push it
        tempArray.push(element);
      }
    }
  }

  getFlattenedArray(this, depth);
  return tempArray;
};

// Usage
const arr = [1, 2, [3, 4, [5, 6]]];

console.log(arr.myFlat());     // [1, 2, 3, 4, [5, 6]]  — depth 1
console.log(arr.myFlat(2));    // [1, 2, 3, 4, 5, 6]    — depth 2
console.log(arr.myFlat(Infinity)); // [1, 2, 3, 4, 5, 6]
```

**How the recursion works:**
1. Loop over the array
2. If an element is an array and depth > 0 → call `getFlattenedArray` again with that element and `depth - 1`
3. If an element is not an array (or depth is 0) → push it into `tempArray`
4. Once all recursion unwinds, return `tempArray`

## Polyfill for `Function.prototype.call()`

### How `call()` Works

`call()` lets a function borrow an object's context. It calls the function **immediately** with `this` set to the provided object.

```js
const obj = { name: 'Prakash', city: 'Delhi' };

function getDetails(country) {
  console.log(`Hi, my name is ${this.name} and I live in ${this.city}, ${country}`);
}

getDetails.call(obj, 'India');
// Hi, my name is Prakash and I live in Delhi, India
```

### Implementing `myCall`

The trick: temporarily add the function as a method on the context object, call it (so `this` naturally points to the object), then delete it.

```js
Function.prototype.myCall = function (context, ...args) {
  // Edge case: context must be an object
  if (typeof context !== 'object' || context === null) {
    throw new TypeError('context must be an object');
  }

  // Edge case: this must be a function
  if (typeof this !== 'function') {
    throw new TypeError('myCall must be called on a function');
  }

  // Temporarily add this function to the context object
  context.wrapperFunction = this;

  // Call the function — 'this' inside it will point to context
  context.wrapperFunction(...args);

  // Clean up — remove the temporary property
  delete context.wrapperFunction;
};

// Usage
const obj = { name: 'Prakash', city: 'Delhi' };

function getDetails(country) {
  console.log(`Hi, my name is ${this.name} and I live in ${this.city}, ${country}`);
}

getDetails.myCall(obj, 'India');
// Hi, my name is Prakash and I live in Delhi, India
```

## Polyfill for `Function.prototype.apply()`

### How `apply()` Works

`apply()` works exactly like `call()`, except arguments are passed as an **array** instead of individually.

```js
getDetails.apply(obj, ['India']); // same result as call
```

### Implementing `myApply`

```js
Function.prototype.myApply = function (context, args) {
  // Edge case: context must be an object
  if (typeof context !== 'object' || context === null) {
    throw new TypeError('context must be an object');
  }

  // Edge case: args must be an array if provided
  if (args !== undefined && !Array.isArray(args)) {
    throw new TypeError('args must be an array');
  }

  // Edge case: this must be a function
  if (typeof this !== 'function') {
    throw new TypeError('myApply must be called on a function');
  }

  context.wrapperFunction = this;

  // Spread the args array when calling
  context.wrapperFunction(...(args || []));

  delete context.wrapperFunction;
};

// Usage
getDetails.myApply(obj, ['India']);
// Hi, my name is Prakash and I live in Delhi, India
```

**`call` vs `apply`:**

| | `call` | `apply` |
|---|---|---|
| Arguments | Passed individually: `fn.call(obj, a, b)` | Passed as array: `fn.apply(obj, [a, b])` |
| Calls function | Immediately | Immediately |
| Returns | `undefined` (result of the function) | `undefined` (result of the function) |

## Polyfill for `Function.prototype.bind()`

### How `bind()` Works

`bind()` does **not** call the function immediately. It returns a **new function** with `this` permanently set to the given object. You call that new function whenever you want.

```js
const obj = { name: 'Prakash', city: 'Delhi' };

function getDetails(country) {
  console.log(`Hi, my name is ${this.name} and I live in ${this.city}, ${country}`);
}

const boundFn = getDetails.bind(obj, 'India');
boundFn(); // Hi, my name is Prakash and I live in Delhi, India
```

### Implementing `myBind`

```js
Function.prototype.myBind = function (context, ...args) {
  // Edge case: context must be an object
  if (typeof context !== 'object' || context === null) {
    throw new TypeError('context must be an object');
  }

  // Edge case: this must be a function
  if (typeof this !== 'function') {
    throw new TypeError('myBind must be called on a function');
  }

  // Store the function reference
  context.wrapperFunction = this;

  // Return a NEW function — don't call it yet
  return function (...rest) {
    // When the returned function is eventually called,
    // spread both the pre-bound args and any new args passed at call time
    context.wrapperFunction(...args, ...rest);
    delete context.wrapperFunction;
  };
};

// Usage — args at bind time
const boundFn = getDetails.myBind(obj, 'India');
boundFn(); // Hi, my name is Prakash and I live in Delhi, India

// Usage — args at call time
const boundFn2 = getDetails.myBind(obj);
boundFn2('India'); // Hi, my name is Prakash and I live in Delhi, India
```

**`call` / `apply` vs `bind`:**

| | `call` / `apply` | `bind` |
|---|---|---|
| Calls function | Immediately | No — returns a new function |
| Returns | Result of function | A new bound function |
| When to use | When you want to invoke now | When you want to invoke later |

## Quick Reference — All Polyfills

| Method | Attached to | Returns | Key behaviour |
|---|---|---|---|
| `myMap` | `Array.prototype` | New array | Transforms every element via callback |
| `myFilter` | `Array.prototype` | New array | Keeps elements where callback returns `true` |
| `myReduce` | `Array.prototype` | Single value | Accumulates all elements into one result |
| `myFlat` | `Array.prototype` | New array | Flattens nested arrays up to given depth via recursion |
| `myCall` | `Function.prototype` | Function result | Calls function immediately with given `this` and args |
| `myApply` | `Function.prototype` | Function result | Same as `myCall` but args passed as array |
| `myBind` | `Function.prototype` | New function | Returns new function with `this` permanently bound |

---

## Summary

- A **polyfill** is your own implementation of a built-in method, used as a fallback for environments that don't support it natively.
- Array method polyfills are added to **`Array.prototype`**; function method polyfills are added to **`Function.prototype`**.
- Inside a prototype method, **`this`** refers to the array or function calling the method.
- **Edge cases to always check:**
    - `!Array.isArray(this)` — confirm the method is being called on an array
    - `typeof callback !== 'function'` — confirm the callback is callable, throw `TypeError` if not
    - Empty array (`this.length === 0`) — return early with `[]` for map/filter/flat, throw for reduce without initial value
    - Single element with no initial value for reduce — return that element directly
    - Negative or non-number depth for flat — throw a `RangeError`
    - For `call`/`apply`/`bind` — check context is an object and not `null`; for apply, check args is an array
- `map` and `filter` return a **new array**; `reduce` returns a **single value**.
- `flat` uses **recursion** — when an element is a nested array, call the helper function again with `depth - 1`.
- `call` and `apply` invoke the function immediately; `bind` returns a new function to call later.
- The core trick for `call`, `apply`, and `bind` polyfills: **temporarily add the function to the context object**, call it (so `this` naturally points to that object), then **delete it**.
