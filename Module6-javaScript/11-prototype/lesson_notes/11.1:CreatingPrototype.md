# JavaScript Prototype

JavaScript uses a **prototype-based object model**, meaning objects inherit properties and methods from other objects through prototypes rather than traditional classes.

Some important points about JavaScript's prototype system are:

* Functions, arrays, and strings are specialized objects.
* Inheritance is handled through prototypes rather than classes.
* Prototypes define how objects share properties and methods.
* Objects can access properties and methods that exist on their prototype.

---

# Prototype in JavaScript

A **prototype** acts as a shared blueprint that stores common methods and properties for objects of the same type.

Instead of creating separate copies of methods for every object, JavaScript stores shared methods in a prototype. All objects of that type can then access those methods through the prototype chain.

## Example

```javascript
Object.prototype.print = function () {
    console.log('I am from object prototype')
}

let b = {
    name: 'Pranjal',
    age: 21
}

b.print()
```

### Output

```text
I am from object prototype
```

### Explanation

```javascript
Object.prototype.print = function () {
    console.log('I am from object prototype')
}
```

Adds a new method called `print()` to `Object.prototype`.

```javascript
let b = {
    name: 'Pranjal',
    age: 21
}
```

Creates an object named `b` with two properties:

* `name`
* `age`

```javascript
b.print()
```

Calls the `print()` method.

Although `b` does not contain a `print()` method directly, JavaScript looks up the prototype chain and finds it in `Object.prototype`.

### Key Points

* Most objects have a prototype.
* Objects created with `Object.create(null)` do not have a prototype.
* Adding a method to a prototype makes it available to all instances.
* Shared methods reduce code duplication and improve efficiency.

---

# Working of Prototype in JavaScript

Every JavaScript object contains an internal **[[Prototype]]** reference that enables inheritance.

When a property or method is accessed:

1. JavaScript checks the object itself.
2. If the property is not found, JavaScript checks the object's prototype.
3. The search continues up the prototype chain.
4. The search stops when the property is found or when `null` is reached.

### Important Points

* Every JavaScript object has an internal `[[Prototype]]`.
* Functions have a `prototype` property.
* Objects created using constructors inherit from the constructor's prototype.
* Methods stored in prototypes are shared by all instances.
* Changes to a prototype affect both existing and future instances.

# Creating Constructor Functions

A **constructor function** is used to create and initialize objects using the `new` keyword.

Constructor functions:

* Define object properties.
* Allow creation of multiple object instances.
* Support shared behavior through prototypes.

## Example

```javascript
function Person(name) {
    this.name = name;
}

Person.prototype.sayHello = function () {
    console.log(`Hello, my name is ${this.name}.`);
};

const n = new Person("Sheema");

n.sayHello();
```

### Output

```text
Hello, my name is Sheema.
```

### Explanation

```javascript
function Person(name) {
    this.name = name;
}
```

Defines a constructor function named `Person`.

```javascript
this.name = name;
```

Stores the passed name in the created object.

```javascript
Person.prototype.sayHello = function () {
    console.log(`Hello, my name is ${this.name}.`);
};
```

Adds the `sayHello()` method to `Person.prototype`.

```javascript
const n = new Person("Sheema");
```

Creates a new `Person` object.

```javascript
n.sayHello();
```

Calls the inherited method.

### Key Points

* `Person` is a constructor function.
* `sayHello()` is shared by all `Person` objects.
* `new Person("Sheema")` creates a new object.
* The object inherits methods from `Person.prototype`.

# Adding Method to Prototype

Adding methods to a prototype allows all instances of an object type to share the same functionality.

### Benefits

* Method is defined once.
* All current instances can use it.
* Future instances can also use it.

## Example

```javascript
let a1 = [1, 2, 3, 4, 5]

let a2 = [5, 6, 7, 8, 9]

Array.prototype.sum = function () {
    let sum = 0

    for (let i = 0; i < this.length; i++) {
        sum += this[i]
    }

    return sum
}

console.log(a1.sum())

console.log(a2.sum())
```

### Output

```text
15
35
```

### Explanation

```javascript
Array.prototype.sum = function () {
```

Adds a `sum()` method to all arrays.

```javascript
let sum = 0
```

Creates a variable to store the total.

```javascript
for (let i = 0; i < this.length; i++) {
    sum += this[i]
}
```

Loops through every array element and adds it to `sum`.

```javascript
return sum
```

Returns the final total.

### Key Points

* `sum()` becomes available to all arrays.
* `this` refers to the current array.
* `a1.sum()` returns 15.
* `a2.sum()` returns 35.

# Prototype Inheritance

Prototype inheritance allows objects to inherit properties and methods from other objects through the prototype chain.

### Benefits

* Shared behavior without duplicated code.
* Reuse of methods and properties.
* Simple inheritance mechanism.

## Example

```javascript
function Animal(name) {
    this.name = name;
}

Animal.prototype.speak = function () {
    console.log(`${this.name} makes a noise.`);
};

function Dog(name) {
    Animal.call(this, name);
}

Dog.prototype = Object.create(Animal.prototype);

Dog.prototype.constructor = Dog;

Dog.prototype.speak = function () {
    console.log(`${this.name} barks.`);
};

const dog = new Dog('Rex');

dog.speak();
```

### Output

```text
Rex barks.
```

### Explanation

```javascript
function Animal(name) {
    this.name = name;
}
```

Creates the parent constructor.

```javascript
Animal.prototype.speak = function () {
    console.log(`${this.name} makes a noise.`);
};
```

Adds a shared method to Animal.

```javascript
function Dog(name) {
    Animal.call(this, name);
}
```

Creates the child constructor and calls the parent constructor.

```javascript
Dog.prototype = Object.create(Animal.prototype);
```

Sets up inheritance.

```javascript
Dog.prototype.constructor = Dog;
```

Restores the constructor reference.

```javascript
Dog.prototype.speak = function () {
    console.log(`${this.name} barks.`);
};
```

Overrides the parent method.

### Key Points

* `Animal` is the parent.
* `Dog` is the child.
* `Dog` inherits from `Animal`.
* `Dog` overrides `speak()`.
* `Object.create()` establishes prototype inheritance.

# Advanced Prototype Use Cases

## 1. Extending Built-in Objects

JavaScript allows developers to extend built-in objects by adding methods to their prototypes.

### Benefits

* Add custom functionality.
* Reuse methods across all instances.
* No need to modify individual objects.

### Example

```javascript
Array.prototype.first = function () {
    return this[0];
};

const n = [10, 20, 30, 40];

console.log(n.first());
```

### Output

```text
10
```

### Explanation

```javascript
Array.prototype.first = function () {
    return this[0];
};
```

Adds a new method called `first()` to all arrays.

```javascript
return this[0];
```

Returns the first element of the array.

### Key Points

* Every array can use `first()`.
* `this` refers to the current array.
* The original array structure is unchanged.

---

## 2. Shared Methods for Performance Optimization

Using prototypes allows all instances to share the same method instead of creating duplicates.

### Benefits

* Reduced memory usage.
* Improved efficiency.
* Better performance with many objects.

### Example

```javascript
function Person(name, age) {
    this.name = name;
    this.age = age;
}

Person.prototype.introduce = function () {
    return `Hello, my name is ${this.name} and I am ${this.age} years old.`;
};

const person1 = new Person('Pranjal', 25);

const person2 = new Person('Ayaan', 30);

console.log(person1.introduce());

console.log(person2.introduce());
```

### Output

```text
Hello, my name is Pranjal and I am 25 years old.

Hello, my name is Ayaan and I am 30 years old.
```

### Key Points

* `introduce()` is stored once.
* Both objects share the same method.
* Memory usage is reduced.
* Functionality is inherited through the prototype chain.

---

## 3. Dynamic Method Assignment

JavaScript allows methods to be added or modified while the program is running.

### Benefits

* Extend functionality dynamically.
* Customize specific objects.
* Modify behavior without changing constructors.

### Example

```javascript
function Person(name, age) {
    this.name = name;
    this.age = age;
}

const person1 = new Person('Pranshi', 25);

person1.introduce = function () {
    return `Hi, I am ${this.name} and I am ${this.age} years old.`;
};

console.log(person1.introduce());
```

### Output

```text
Hi, I am Pranshi and I am 25 years old.
```

### Explanation

```javascript
person1.introduce = function () {
```

Adds a method directly to `person1`.

The method:

* Exists only on `person1`.
* Is not inherited by other objects.
* Is not stored on the prototype.

### Key Points

* Methods can be added at runtime.
* Only the specified object receives the method.
* Other instances do not inherit it.

# Prototype Chain in JavaScript

Many JavaScript data types are specialized objects that inherit from `Object`.

## Example

```javascript
let o = {
    name: "Pranjal",
    age: 21
}

let a = [1, 2, 3, 4, 5]

let s = "Hello GFG"

function p() {
    console.log('My name is xyzabc')
}

Object.prototype.common = function () {
    console.log('I am a shared method from prototype')
}

o.common()

a.common()

s.common()

p.common()
```

### Output

```text
I am a shared method from prototype

I am a shared method from prototype

I am a shared method from prototype

I am a shared method from prototype
```

### Explanation

```javascript
Object.prototype.common = function () {
    console.log('I am a shared method from prototype')
}
```

Adds a shared method to `Object.prototype`.

Because arrays, strings, functions, and regular objects ultimately inherit from `Object`, they can all access `common()`.

### Key Points

* Functions, arrays, and strings are specialized objects.
* `Object` acts as the parent type.
* Shared methods can be accessed through the prototype chain.
* This inheritance structure is called the **prototype chain**.

---

# Summary

A **prototype** is a shared object that stores methods and properties used by other objects. JavaScript uses prototypes to implement inheritance, allowing objects to share functionality efficiently. Constructor functions, prototype methods, prototype inheritance, built-in object extensions, and the prototype chain all rely on this mechanism. By storing methods in prototypes rather than individual objects, JavaScript improves memory efficiency, code reuse, and performance.
