# JavaScript Static Methods and Properties

JavaScript **Static Methods and Properties** are members that belong to the class itself rather than to objects created from the class. They are accessed directly through the class name and are commonly used for utility functions, helper methods, counters, configuration values, and shared class-level data.

Some important points about static members are:

* Declared using the `static` keyword.
* Belong to the class itself.
* Accessed using the class name.
* Cannot be accessed directly through class instances.
* Useful for utility methods and shared data.
* Often used in design patterns such as Factory and Singleton.

---

# Syntax

Static methods are declared using the `static` keyword inside a class.

```javascript
class ClassName {

    static methodName() {

        // method logic

    }

}
```

### Explanation

```javascript
class ClassName
```

Defines a class.

```javascript
static methodName()
```

Defines a static method.

Unlike regular methods, static methods belong to the class itself.

### Calling a Static Method

```javascript
ClassName.methodName()
```

The method is called using the class name instead of an object.

# Basic Example of Static Methods

## Example

```javascript
class MathUtils {

    static add(a, b) {
        return a + b;
    }

    static multiply(a, b) {

console.log(MathUtils.add(5, 3));

console.log(MathUtils.multiply(4, 6));
```

```text
8

24
```

### Static Method add()

```javascript
static add(a, b) {
    return a + b;
}
```

Accepts two numbers and returns their sum.

---

### Static Method multiply()

```javascript
static multiply(a, b) {
    return a * b;
}
```

Accepts two numbers and returns their product.

---

### Calling Static Methods

```javascript
MathUtils.add(5, 3)
```

Returns:

```text
8
```

```javascript
MathUtils.multiply(4, 6)
```

Returns:

```text

```

---

### Key Points

* No object is created.
* Methods belong directly to `MathUtils`.
* Accessed using the class name.
* Useful for utility operations.

# Characteristics of Static Methods

## 1. Class-Based

Static methods belong to the class rather than an instance.

```javascript
ClassName.method()
```

instead of:

```javascript
object.method()
```

---

## 2. No Access to Instance Properties

Static methods can access `this`, but `this` refers to the class itself.

It does not refer to a specific object instance.

---

## 3. Common Use Cases

Static methods are commonly used for:

* Mathematical calculations
* String manipulation
* Validation functions
* Factory methods
* Shared business logic
* Design patterns

---

# Use Cases of Static Methods

# 1. Static Method Using Math.max()

Static methods are useful for wrapping utility functions that do not depend on object instances.

## Example

```javascript
class Calc {

    static getMax(...numbers) {

        return Math.max(...numbers);

    }

}

console.log(
    Calc.getMax(1, 5, 3, 9)
);
```

### Output

```text
9
```

---

## Explanation

### Static Method

```javascript
static getMax(...numbers)
```

Accepts any number of values.

---

### Math.max()

```javascript
Math.max(...numbers)
```

Returns the largest number.

---

### Method Call

```javascript
Calc.getMax(1, 5, 3, 9)
```

Returns:

```text
9
```

---

### Key Points

* Uses a static utility method.
* No object creation required.
* Useful for calculations and helper functions.

# 3. Static Method Counter

Static properties and methods can manage class-level data.

## Example

```javascript
class Count {

    static c = 0;

    static inc() {

        return ++Count.c;

    }

    static reset() {

        Count.c = 0;

    }

}

console.log(Count.inc());

console.log(Count.inc());

Count.reset();

console.log(Count.inc());
```

### Output

```text
1

2

1
```

---

## Explanation

### Static Property

```javascript
static c = 0;
```

Stores the counter value.

This property belongs to the class.

---

### Increment Method

```javascript
static inc()
```

Increases the counter.

```javascript
return ++Count.c;
```

Updates and returns the new value.

---

### Reset Method

```javascript
static reset()
```

Resets the counter back to zero.

---

### Execution

```javascript
Count.inc()
```

Returns:

```text
1
```

Second call:

```javascript
Count.inc()
```

Returns:

```text
2
```

After reset:

```javascript
Count.inc()
```

Returns:

```text
1
```

---

### Key Points

* Static properties store shared data.
* All code accesses the same property.
* Useful for counters and tracking values.

# 4. Static Method Factory Pattern

A static method can create and return objects.

This is called a Factory Method.

## Example

```javascript
class User {

    constructor(name, age) {

        this.name = name;
        this.age = age;

    }

    static createUser(name, age) {

        return new User(name, age);

    }

}

const user =
User.createUser('Ajay', 30);

console.log(user);
```

### Output

```text
User { name: 'Ajay', age: 30 }
```

---

## Explanation

### Constructor

```javascript
constructor(name, age)
```

Initializes user properties.

---

### Factory Method

```javascript
static createUser(name, age)
```

Creates and returns a new User object.

---

### Creating an Object

```javascript
User.createUser('Ajay', 30)
```

Returns:

```javascript
new User('Ajay', 30)
```

---

### Key Points

* Simplifies object creation.
* Hides object creation logic.
* Useful in Factory design patterns.

---

# 5. Static Method Singleton Pattern

Static methods can ensure only one object exists.

This is called the Singleton Pattern.

## Example

```javascript
class DB {

    static instance;

    constructor() {

        if (DB.instance) {

            return DB.instance;

        }

        DB.instance = this;

    }

    static getInstance() {

        if (!DB.instance) {

            DB.instance =
            new DB();

        }

        return DB.instance;

    }

}

const obj1 = new DB();

const obj2 = new DB();

console.log(obj1 === obj2);
```

### Output

```text
true
```

---

## Explanation

### Static Property

```javascript
static instance
```

Stores the single object.

---

### Constructor Check

```javascript
if(DB.instance)
```

Returns the existing object if it already exists.

---

### Static Method

```javascript
static getInstance()
```

Creates an object only if one does not already exist.

---

### Comparison

```javascript
obj1 === obj2
```

Returns:

```text
true
```

because both variables reference the same object.

---

### Key Points

* Ensures only one instance exists.
* Provides a global access point.
* Commonly used in database and configuration systems.

# Static Properties

A static property belongs to the class itself rather than to individual objects.

All objects share the same static property.

---

## Example

```javascript
class Children {

    static ID = 1;

    constructor(name, age) {

        this.name = name;
        this.age = age;

        this.id = Children.ID++;

    }

}

let child1 =
new Children("Emma", 11);

let child2 =
new Children("James", 19);

let child3 =
new Children("John", 9);

console.log(child1.id);

console.log(child2.id);

console.log(child3.id);
```

### Output

```text
1

2

3
```

---

## Explanation

### Static Property

```javascript
static ID = 1;
```

Stores the next available ID.

---

### Constructor

```javascript
this.id = Children.ID++;
```

Assigns the current ID and then increments it.

---

### First Object

```javascript
new Children("Emma",11)
```

Receives:

```text
id = 1
```

---

### Second Object

```javascript
new Children("James",19)
```

Receives:

```text
id = 2
```

---

### Third Object

```javascript
new Children("John",9)
```

Receives:

```text
id = 3
```

---

### Key Points

* Static properties are shared by all objects.
* They belong to the class.
* Useful for IDs, counters, and configuration values.

---

# Accessing Static Properties and Methods

Static members are accessed using the class name.

## Accessing a Static Property

```javascript
console.log(Children.ID);
```

Accesses the static property directly from the class.

---

## Accessing a Static Method

```javascript
Children.sortByAge(child1, child2);
```

Calls a static method through the class name.

---

# Summary

Static methods and properties belong to the class itself rather than objects created from the class. They are declared using the `static` keyword and are accessed through the class name. Static methods are commonly used for utility functions, validation, calculations, factory methods, and design patterns such as Singleton. Static properties store shared data that is common to all objects, making them useful for counters, unique IDs, and configuration values. By keeping class-level functionality separate from instance-level functionality, static members help organize code and improve maintainability.
