# JavaScript Private Properties

JavaScript **Private Properties** and **Private Methods** allow class data and functionality to be hidden from code outside the class. They support **encapsulation**, one of the core principles of Object-Oriented Programming (OOP), by protecting internal implementation details and allowing controlled access through public methods.

Some important points about private members are:

* Restrict direct external access to class data.
* Allow interaction only through controlled class methods.
* Improve security and data integrity.
* Reduce unintended modifications.
* Declared using the `#` symbol.
* Accessible only inside the class where they are defined.

---

# What are Private Properties?

Private properties are variables that belong to a class but cannot be accessed or modified directly from outside the class.

They help keep important data protected and prevent accidental changes.

---

# Public Property Example

Before understanding private properties, consider a class with a public property.

## Example

```javascript
class User {

    constructor(id) {

        this.id = id;

    }

}

const user = new User('123');

console.log(user.id);

user.id = '321';

console.log(user.id);
```

### Output

```text
123

321
```

---

## Explanation

### Constructor

```javascript
constructor(id) {
    this.id = id;
}
```

Creates a public property called `id`.

---

### Accessing the Property

```javascript
console.log(user.id);
```

Outputs:

```text
123
```

because public properties can be accessed directly.

---

### Modifying the Property

```javascript
user.id = '321';
```

Changes the value of `id`.

---

### Output

```text
321
```

The property was successfully modified because it is public.

---

## Problem with Public Properties

Since anyone can modify the property:

```javascript
user.id = '321';
```

important data can be changed unintentionally.

This may lead to bugs or security issues.

---

# Creating a Private Property

JavaScript provides private fields using the `#` symbol.

## Example

```javascript
class User {

    #id;

    constructor(id) {

        this.#id = id;

    }

    getId() {

        return this.#id;

    }

    changeId(newId) {

        this.#id = newId;

    }

}

const user = new User('123');

console.log(user.getId());

user.changeId('321');

console.log(user.getId());
```

### Output

```text
123

321
```

---

## Explanation

### Private Property

```javascript
#id;
```

Declares a private property named `id`.

The `#` symbol makes it accessible only inside the class.

---

### Constructor

```javascript
constructor(id) {
    this.#id = id;
}
```

Stores the provided ID in the private field.

---

### Getter Method

```javascript
getId() {
    return this.#id;
}
```

Returns the private ID value.

This provides controlled access.

---

### Modifier Method

```javascript
changeId(newId) {
    this.#id = newId;
}
```

Allows the ID to be changed through a class method.

---

### Using the Methods

```javascript
user.getId();
```

Returns:

```text
123
```

---

```javascript
user.changeId('321');
```

Updates the private ID.

---

```javascript
user.getId();
```

Returns:

```text
321
```

---

# Attempting Direct Access

Private properties cannot be accessed outside the class.

## Example

```javascript
user.#id = '321';
```

### Result

```text
SyntaxError:
Private field '#id' must be declared
in an enclosing class
```

---

## Explanation

JavaScript blocks direct access to private fields.

Only methods inside the class can access:

```javascript
this.#id
```

This ensures complete protection of the data.

---

# Features of Private Properties

## 1. Private Field Syntax

Private properties use the `#` symbol.

```javascript
#id;
```

This identifies the property as private.

---

## 2. Encapsulation

Private properties hide internal implementation details.

Outside code cannot directly modify them.

---

## 3. Controlled Access

Access is provided through class methods.

Example:

```javascript
getId()
```

and

```javascript
changeId()
```

---

## 4. Improved Reliability

Because data cannot be modified directly, the class maintains better control over its state.

---

# Private Methods

Private methods work similarly to private properties.

A private method can only be called from inside the class.

---

## Example

```javascript
class User {

    #id;

    constructor(id) {

        this.#id = id;

    }

    #showId() {

        return this.#id;

    }

    display() {

        console.log(this.#showId());

    }

}

const user = new User('123');

user.display();
```

### Output

```text
123
```

---

## Explanation

### Private Method

```javascript
#showId()
```

Defines a private method.

Only methods inside the class can call it.

---

### Public Method

```javascript
display()
```

Calls the private method.

```javascript
this.#showId()
```

and prints the returned value.

---

### Method Call

```javascript
user.display();
```

Outputs:

```text
123
```

---

# Attempting to Access a Private Method

## Example

```javascript
user.#showId();
```

### Result

```text
SyntaxError
```

---

## Explanation

Private methods are hidden from external code.

Only the class itself can use them.

---

# Why Use Private Methods?

Private methods are useful when:

* Logic should remain internal to the class.
* Helper methods should not be accessible externally.
* Internal functionality should be protected.
* Complex operations should be hidden from users of the class.

---

# Features of Private Methods

## 1. Declared Using

```javascript
#methodName()
```

The `#` symbol makes the method private.

---

## 2. Internal Use Only

Private methods can only be called by other methods in the same class.

---

## 3. Encapsulation

They hide implementation details from external code.

---

## 4. Better Maintainability

Internal logic can change without affecting outside code.

---

# Limitations and Browser Support

Private properties and methods have some limitations.

---

## 1. Relatively New Feature

The `#` syntax is a modern JavaScript feature.

Older environments may not support it.

Developers may need tools such as Babel for compatibility.

---

## 2. No External Access

Once declared private:

```javascript
#id
```

or

```javascript
#showId()
```

cannot be accessed outside the class.

This restriction is enforced by JavaScript itself.

---

## 3. Strict Encapsulation

There is no alternative syntax for accessing private members externally.

They are completely hidden outside the class.

---

# Summary

Private properties and private methods provide a way to hide data and functionality inside a JavaScript class. They are declared using the `#` symbol and can only be accessed within the class that defines them. Private properties protect important data from direct modification, while private methods hide internal logic from external code. Together, they improve encapsulation, reliability, maintainability, and security by ensuring that class internals remain under the control of the class itself.
