# Skeleton UI in React

Skeleton UI components act as **placeholder previews** of content while data is loading. Instead of a blank screen or spinner, the user sees gray "ghost" shapes that mimic the layout of the real content — improving **perceived performance** even though the actual load time hasn't changed.

This document demonstrates skeleton loading using **five different methods**, all applied to the same real app: a **Users List page** and a **User Details page** that fetch from `jsonplaceholder.typicode.com`.

---

## The App We're Building Skeletons For

```jsx
// UserCard.jsx
import { Link } from "react-router-dom";

const UserCard = ({ user }) => {
  return (
    <Link
      to={`/user/${user.id}`}
      className="bg-gray-700 w-full max-w-md p-4 rounded-lg shadow-md mb-4 flex items-center space-x-4 hover:bg-gray-700 transition"
    >
      <div className="w-12 h-12 rounded-full bg-blue-600 flex items-center justify-center text-white font-bold text-lg">
        {user.name.charAt(0)}
      </div>
      <div>
        <h2 className="text-lg font-semibold text-white">{user.name}</h2>
        <p className="text-gray-300">{user.email}</p>
        <p className="text-gray-400 text-sm">{user.address.city}</p>
      </div>
    </Link>
  );
};

export default UserCard;
```

The layout we need to mimic:
- A **48×48 circular avatar** (`w-12 h-12 rounded-full`)
- A **title line** (name)
- Two smaller **text lines** (email, city)

We'll build a skeleton matching this shape using each method, then wire it into `UsersPage` and `UserDetailsPage`.

## Method 1: Custom Skeleton with Tailwind CSS

No dependencies — just a reusable `<div>` with `animate-pulse` and a background color.

### Base skeleton element

```jsx
// Skeleton.jsx
export default function Skeleton({ className }) {
  return (
    <div className={`bg-gray-600 animate-pulse rounded ${className}`}></div>
  );
}
```

### `SkeletonCard.jsx` matching `UserCard`

```jsx
import Skeleton from "./Skeleton";

const SkeletonCard = () => {
  return (
    <div className="bg-gray-700 w-full max-w-md p-4 rounded-lg mb-4 flex items-center space-x-4">
      {/* Avatar circle */}
      <Skeleton className="h-12 w-12 rounded-full" />

      {/* Text lines */}
      <div className="flex-1 space-y-2">
        <Skeleton className="h-5 w-3/4" />   {/* name */}
        <Skeleton className="h-4 w-full" />  {/* email */}
        <Skeleton className="h-4 w-1/2" />   {/* city */}
      </div>
    </div>
  );
};

export default SkeletonCard;
```

### Wiring into `UsersPage.jsx`

```jsx
import { useEffect, useState } from "react";
import UserCard from "../components/UserCard";
import SkeletonCard from "../components/SkeletonCard";

const UsersPage = () => {
  const [users, setUsers] = useState([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    const getUsers = async () => {
      try {
        const response = await fetch("https://jsonplaceholder.typicode.com/users");
        const data = await response.json();
        setUsers(data);
      } catch (error) {
        console.error("Error fetching users:", error);
      } finally {
        setLoading(false);
      }
    };
    getUsers();
  }, []);

  return (
    <div className="min-h-screen bg-gray-900 p-6 text-gray-100">
      <h1 className="text-2xl font-bold mb-6 text-center text-white">Users List</h1>
      <div className="grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 gap-6 justify-items-center">
        {loading
          ? Array.from({ length: 10 }).map((_, index) => <SkeletonCard key={index} />)
          : users.map((user) => <UserCard key={user.id} user={user} />)}
      </div>
    </div>
  );
};

export default UsersPage;
```

**Pros**: zero dependencies, full control over markup/colors.
**Cons**: you re-implement the shimmer/pulse logic and every shape by hand.

## Method 2: `react-loading-skeleton` Library

Automatically sizes placeholders and ships a theming wrapper.

### Installation

```bash
npm install react-loading-skeleton
```

### `SkeletonCard.jsx`

```jsx
import Skeleton from "react-loading-skeleton";

const SkeletonCard = () => {
  return (
    <div className="bg-gray-700 w-full max-w-md p-4 rounded-lg mb-4 flex items-center space-x-4">
      {/* Avatar circle */}
      <div>
        <Skeleton circle height={48} width={48} />
      </div>

      {/* Text lines */}

export default SkeletonCard;
```

### `UserDetailsPage.jsx` — inline skeleton, no separate component needed

```jsx
import { useParams, Link } from "react-router-dom";
import { useEffect, useState } from "react";
import Skeleton from "react-loading-skeleton";

const UserDetailsPage = () => {
  const { id } = useParams();
  const [user, setUser] = useState(null);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    const getUser = async () => {
      try {
        const response = await fetch(`https://jsonplaceholder.typicode.com/users/${id}`);
        const data = await response.json();
        setUser(data);
      } catch (error) {
        console.error("Error fetching user details:", error);
      } finally {
        setLoading(false);
      }
    };
    getUser();
  }, [id]);

  return (
    <div className="min-h-screen bg-gray-900 flex flex-col items-center p-6 text-gray-100">
      <Link to="/" className="text-blue-400 hover:underline self-start mb-4 font-semibold">
        ← Back to Users
      </Link>

      {loading ? (
        <div className="bg-gray-700 w-full max-w-md p-6 rounded-lg mt-6">
          <Skeleton height={24} width="50%" />
          <Skeleton height={20} width="70%" className="mt-2" />
          <Skeleton height={16} width="60%" className="mt-2" />
        </div>
      ) : (
        <div className="bg-gray-800 w-full max-w-md p-6 rounded-lg shadow-md mt-6">
          <h2 className="text-xl font-bold text-white mb-2">{user.name}</h2>
          <p className="text-gray-300 mb-1">
            <strong className="text-gray-100">Email:</strong> {user.email}
          </p>
          <p className="text-gray-300 mb-1">
            <strong className="text-gray-100">City:</strong> {user.address.city}
          </p>
        </div>
      )}
    </div>
  );
};

export default UserDetailsPage;
```

### Global theme via `App.jsx`

```jsx
import { BrowserRouter as Router, Routes, Route } from "react-router-dom";
import UsersPage from "./pages/UsersPage";
import UserDetailsPage from "./pages/UserDetailsPage";
import "react-loading-skeleton/dist/skeleton.css"; // required stylesheet
import { SkeletonTheme } from "react-loading-skeleton";

const App = () => {
  return (
    <SkeletonTheme baseColor="#1e293b" highlightColor="#334155">
      <Router>
        <Routes>
          <Route path="/" element={<UsersPage />} />
          <Route path="/user/:id" element={<UserDetailsPage />} />
        </Routes>
      </Router>
    </SkeletonTheme>
  );
};

export default App;
```

`SkeletonTheme` wraps the entire app once, so `baseColor`/`highlightColor` apply consistently to every `<Skeleton>` used anywhere — matching the app's dark `gray-900`/`gray-700` palette.

**Pros**: auto-sizing, one global theme, minimal markup.
**Cons**: extra dependency + required CSS import.

## Method 3: Material UI (`@mui/material`) `<Skeleton>`

Best when the rest of the app already uses MUI components, since it auto-matches `Typography` variants.

### Installation

```bash
npm install @mui/material @emotion/react @emotion/styled
```

### `SkeletonCard.jsx`

```jsx
import Box from "@mui/material/Box";
import Skeleton from "@mui/material/Skeleton";

const SkeletonCard = () => {
  return (
    <Box
      sx={{
        bgcolor: "grey.800",
        width: "100%",
        maxWidth: 400,
        p: 2,
        borderRadius: 2,
        display: "flex",
        alignItems: "center",
        gap: 2,
        mb: 2,
      }}
    >
      {/* Avatar circle */}
      <Skeleton variant="circular" width={48} height={48} sx={{ bgcolor: "grey.700" }} />

      {/* Text lines */}
      <Box sx={{ flex: 1 }}>
        <Skeleton variant="text" width="80%" height={28} sx={{ bgcolor: "grey.700" }} />
        <Skeleton variant="text" width="60%" height={20} sx={{ bgcolor: "grey.700" }} />
        <Skeleton variant="text" width="40%" height={20} sx={{ bgcolor: "grey.700" }} />
      </Box>
    </Box>
  );
};

export default SkeletonCard;
```

### Usage in `UsersPage.jsx` (same swap-in pattern)

```jsx
{loading
  ? Array.from({ length: 10 }).map((_, index) => <SkeletonCard key={index} />)
  : users.map((user) => <UserCard key={user.id} user={user} />)}
```

### `UserDetailsPage.jsx` skeleton block

```jsx
import Skeleton from "@mui/material/Skeleton";
import Box from "@mui/material/Box";

{loading ? (
  <Box sx={{ bgcolor: "grey.800", width: "100%", maxWidth: 400, p: 3, borderRadius: 2, mt: 3 }}>
    <Skeleton variant="text" width="50%" height={32} sx={{ bgcolor: "grey.700" }} />
    <Skeleton variant="text" width="70%" height={24} sx={{ bgcolor: "grey.700", mt: 1 }} />
    <Skeleton variant="text" width="60%" height={20} sx={{ bgcolor: "grey.700", mt: 1 }} />
  </Box>
) : (
  // real user details JSX
  <></>
)}
```

**Pros**: variants (`circular`, `text`, `rectangular`, `rounded`) map directly onto avatar/name/text; integrates with MUI's theme.
**Cons**: heavier dependency, only worth it if the app is already MUI-based.

## Method 4: shadcn/ui `<Skeleton>`

An unstyled primitive — you fully control the shape with Tailwind classes, same as Method 1, but distributed as a copy-in component via the CLI.

### Installation

```bash
npx shadcn@latest add skeleton
```

This generates:

```tsx
// components/ui/skeleton.tsx
import { cn } from "@/lib/utils";

function Skeleton({ className, ...props }: React.HTMLAttributes<HTMLDivElement>) {
  return (
    <div className={cn("animate-pulse rounded-md bg-muted", className)} {...props} />
  );
}

export { Skeleton };
```

### `SkeletonCard.tsx` matching `UserCard`

```tsx
import { Skeleton } from "@/components/ui/skeleton";

export function SkeletonCard() {
  return (
    <div className="bg-gray-700 w-full max-w-md p-4 rounded-lg mb-4 flex items-center space-x-4">
      {/* Avatar circle */}
      <Skeleton className="h-12 w-12 rounded-full bg-gray-600" />

      {/* Text lines */}
      <div className="flex-1 space-y-2">
        <Skeleton className="h-5 w-3/4 bg-gray-600" />
        <Skeleton className="h-4 w-full bg-gray-600" />
        <Skeleton className="h-4 w-1/2 bg-gray-600" />
      </div>
    </div>
  );
}
```

### `UsersPage.tsx`

```tsx
{loading
  ? Array.from({ length: 10 }).map((_, index) => <SkeletonCard key={index} />)
  : users.map((user) => <UserCard key={user.id} user={user} />)}
```

### `UserDetailsPage.tsx` skeleton block

```tsx
import { Skeleton } from "@/components/ui/skeleton";

{loading ? (
  <div className="bg-gray-700 w-full max-w-md p-6 rounded-lg mt-6 space-y-2">
    <Skeleton className="h-6 w-1/2 bg-gray-600" />
    <Skeleton className="h-5 w-2/3 bg-gray-600" />
    <Skeleton className="h-4 w-3/5 bg-gray-600" />
  </div>
) : (
  // real user details JSX
  <></>
)}
```

**Pros**: no runtime dependency beyond Tailwind, plays perfectly with an existing shadcn-based design system, fully customizable via the `--muted` CSS variable.
**Cons**: you build every shape manually (like Method 1) — no auto-sizing helpers.

## Method 5: Ant Design (`antd`) `<Skeleton>`

Ant Design can auto-generate common layouts (`avatar` + `paragraph`) with a single prop, or be composed from granular sub-components.

### Installation

```bash
npm install antd
```

### Option A — High-level auto layout

```jsx
import { Skeleton } from "antd";

const SkeletonCard = () => {
  return (
    <div
      style={{
        background: "#374151", // gray-700
        width: "100%",
        maxWidth: 400,
        padding: 16,
        borderRadius: 8,
        marginBottom: 16,
      }}
    >
      <Skeleton active avatar paragraph={{ rows: 2 }} />
    </div>
  );
};

export default SkeletonCard;
```

### Option B — Granular layout matching `UserCard` exactly

```jsx
import { Skeleton, Space } from "antd";

const SkeletonCard = () => {
  return (
    <div
      style={{
        background: "#374151",
        width: "100%",
        maxWidth: 400,
        padding: 16,
        borderRadius: 8,
        marginBottom: 16,
        display: "flex",
        alignItems: "center",
        gap: 16,
      }}
    >
      <Skeleton.Avatar active size={48} shape="circle" />
      <Space direction="vertical" size={6} style={{ flex: 1 }}>
        <Skeleton.Input active size="small" style={{ width: "80%" }} />
        <Skeleton.Input active size="small" style={{ width: "60%" }} />
        <Skeleton.Input active size="small" style={{ width: "40%" }} />
      </Space>
    </div>
  );
};

export default SkeletonCard;
```

### `UsersPage.jsx` — unchanged pattern

```jsx
{loading
  ? Array.from({ length: 10 }).map((_, index) => <SkeletonCard key={index} />)
  : users.map((user) => <UserCard key={user.id} user={user} />)}
```

### `UserDetailsPage.jsx` — using the "wrap real content" pattern

Ant Design's `<Skeleton loading={...}>` can wrap the real JSX directly, swapping automatically when `loading` becomes `false` — no ternary needed:

```jsx
import { Skeleton } from "antd";

const UserDetailsPage = () => {
  const { id } = useParams();
  const [user, setUser] = useState(null);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    const getUser = async () => {
      try {
        const response = await fetch(`https://jsonplaceholder.typicode.com/users/${id}`);
        const data = await response.json();
        setUser(data);
      } catch (error) {
        console.error("Error fetching user details:", error);
      } finally {
        setLoading(false);
      }
    };
    getUser();
  }, [id]);

  return (
    <div className="min-h-screen bg-gray-900 flex flex-col items-center p-6 text-gray-100">
      <Link to="/" className="text-blue-400 hover:underline self-start mb-4 font-semibold">
        ← Back to Users
      </Link>

      <div className="bg-gray-800 w-full max-w-md p-6 rounded-lg shadow-md mt-6">
        <Skeleton loading={loading} active paragraph={{ rows: 3 }}>
          {user && (
            <>
              <h2 className="text-xl font-bold text-white mb-2">{user.name}</h2>
              <p className="text-gray-300 mb-1">
                <strong className="text-gray-100">Email:</strong> {user.email}
              </p>
              <p className="text-gray-300 mb-1">
                <strong className="text-gray-100">City:</strong> {user.address.city}
              </p>
            </>
          )}
        </Skeleton>
      </div>
    </div>
  );
};

export default UserDetailsPage;
```

**Pros**: `active` gives shimmer for free, `<Skeleton loading>` wrapping removes the manual ternary, granular sub-components (`Avatar`, `Input`, `Button`, `Image`) cover most shapes.
**Cons**: pulls in the full `antd` design system and its own styling conventions (may clash visually with a Tailwind-first app unless customized via `ConfigProvider`).

## Comparing All Five Methods

| Method | Dependency | Auto-sizing | Theming | Best for |
|---|---|---|---|---|
| Custom Tailwind | None | ❌ manual | Tailwind classes | Small apps, full control, no extra bundle size |
| `react-loading-skeleton` | ~3kb | ✅ | `SkeletonTheme` wrapper | Quick drop-in with app-wide color theme |
| MUI `<Skeleton>` | MUI (if not already installed) | ✅ (matches `Typography`) | MUI theme / `sx` | Apps already built with Material UI |
| shadcn/ui `<Skeleton>` | None (copied in) | ❌ manual | Tailwind / CSS vars (`--muted`) | Apps using shadcn/Tailwind design system |
| Ant Design `<Skeleton>` | antd (if not already installed) | ✅ (`avatar`/`paragraph` props) | `ConfigProvider` theme | Apps already built with Ant Design |

---

## Best Practices (apply to every method)

- **Match real dimensions closely** — the skeleton's avatar/text sizes should mirror the actual rendered content (`h-12 w-12` avatar, similar line heights) to avoid layout shift when data arrives.
- **Animate subtly** — stick to `pulse` (fade in/out) or `wave`/`shimmer` (sliding gradient); fast or jarring animations feel worse than no animation.
- **Preserve accessibility** — add `aria-busy="true"` and `aria-live="polite"` to the loading container so screen readers announce the loading state correctly:

```jsx
<div
  className="grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 gap-6"
  aria-busy={loading}
  aria-live="polite"
>
  {loading
    ? Array.from({ length: 10 }).map((_, i) => <SkeletonCard key={i} />)
    : users.map((user) => <UserCard key={user.id} user={user} />)}
</div>
```

- **Render a fixed, believable count** — showing exactly `10` skeleton cards (matching the typical API page size) feels more natural than showing 1 or 100.
- **Keep the toggle logic simple** — a `loading` boolean and a ternary (or a wrapper component like Ant Design's `<Skeleton loading>`) is all that's needed; no need for complex state machines for basic loading states.
