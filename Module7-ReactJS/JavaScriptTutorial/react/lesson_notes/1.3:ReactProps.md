# React Props

---

## What are Props?

**Props** (short for properties) are the mechanism React uses to pass data from one component to another. They flow in one direction — from **parent to child** — and allow you to create reusable components that display different data each time they are used.

Think of props like arguments you pass to a function — a component accepts props as input and uses them to determine what to display.

---

## The Problem Props Solve

Consider a book app that needs to display three books. Without props, you'd repeat the same JSX three times:

```jsx
const App = () => {
  return (
    <main>
      <h1>Favourite Books</h1>

      <section>
        <h2>Mastering React</h2>
        <p>By Anthony Pham</p>
      </section>

      <section>
        <h2>Practical React</h2>
        <p>By Alex Johnson</p>
      </section>

      <section>
        <h2>React in Action</h2>
        <p>By Bob Climo</p>
      </section>
    </main>
  );
};
```

This works, but it duplicates the structure. With props, you create **one reusable `BookApp` component** and pass different data to each instance:

```jsx
const App = () => {
  return (
    <main>
      <h1>Favourite Books</h1>
      <BookApp title="Mastering React"  author="Anthony Pham"  />
      <BookApp title="Practical React"  author="Alex Johnson"  />
      <BookApp title="React in Action"  author="Bob Climo"     />
    </main>
  );
};
```

---

## Component Hierarchy

React components are arranged in a **tree-like hierarchy**:

```
App  (parent)
├── BookApp  (child)
├── BookApp  (child)
└── BookApp  (child)
```

| Term | Definition |
|---|---|
| **Parent component** | A component that contains other components and passes data down via props |
| **Child component** | A component nested inside a parent — receives data from the parent via props |
| **Sibling components** | Components that share the same parent — they are at the same level in the tree |

Data always flows **downward** — from parent to child. A child cannot send props back up to the parent directly.

---

## Passing Props

Props are passed like HTML attributes — as key-value pairs on the component tag:

```jsx
// Passing string props
<BookApp title="Mastering React" author="Anthony Pham" />

// Passing a number prop
<Card rating={4.5} />

// Passing a boolean prop
<Button disabled={true} />

// Passing a variable as a prop
const coverImage = './mastering-react.svg';
<BookApp cover={coverImage} />
```

- **String props** — use double quotes: `title="Mastering React"`
- **All other props** (numbers, booleans, variables, expressions) — use curly braces: `rating={4.5}`

---

## Receiving Props

The component function receives all passed props as a single **props object** as its first argument:

```jsx
const BookApp = (props) => {
  return (
    <section>
      <h2>{props.title}</h2>
      <p>By {props.author}</p>
    </section>
  );
};
```

Access each value with `props.propName`.

---

## Destructuring Props (Recommended)

Instead of using `props.title`, `props.author` everywhere, you can **destructure** the props object directly in the function signature for cleaner code:

```jsx
// Without destructuring
const BookApp = (props) => {
  return (
    <section>
      <h2>{props.title}</h2>
      <p>By {props.author}</p>
    </section>
  );
};

// With destructuring — cleaner and preferred
const BookApp = ({ title, author }) => {
  return (
    <section>
      <h2>{title}</h2>
      <p>By {author}</p>
    </section>
  );
};
```

Both produce exactly the same result — destructuring is just more readable.

## Passing Images as Props

Images are imported at the top of the file and passed as a prop value using curly braces:

**`BookApp.js`:**

```jsx
import BookApp from './BookApp';
import MasteringReact from './mastering-react.svg';
import PracticalReact from './practical-react.svg';
import ReactInAction from './react-in-action.svg';

const App = () => {
  return (
    <main>
      <h1>Favourite Books</h1>
      <div className="book-list">
        <BookApp
          title="Mastering React"
          author="Anthony Pham"
          cover={MasteringReact}
        />
        <BookApp
          title="Practical React"
          author="Alex Johnson"
          cover={PracticalReact}
        />
        <BookApp
          title="React in Action"
          author="Bob Climo"
          cover={ReactInAction}
        />
      </div>
    </main>
  );
};

export default App;
```

**`Book.js`:**

```jsx
const BookApp = ({ title, cover, author }) => {
  return (
    <section className="book">
      <img src={cover} alt={title} className="book-cover" />
      <h2 className="book-title">{title}</h2>
      <p className="book-author">By {author}</p>
    </section>
  );
};

export default BookApp;
```

## Default vs Named Exports

React components can be exported in two ways, and the import syntax differs:

### Default export

```jsx
// Exporting
const BookApp = () => { ... };
export default BookApp;

// Importing — no curly braces needed, can use any name
import BookApp from './BookApp';
import MyBook from './BookApp'; // also valid
```

### Named export

```jsx
// Exporting
export const BookApp = () => { ... };

// Importing — must use curly braces and the exact name
import { BookApp } from './BookApp';
```

> A module can only have **one default export** but can have **multiple named exports**.

## Adding CSS to the App

Import a CSS file directly into the component file — it applies globally:

```jsx
import './style.css';
```

**`style.css`:**

```css
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

body {
  font-family: system-ui, sans-serif;
  display: flex;
  justify-content: center;
  align-items: center;
  height: 100vh;
}

h1 {
  margin-bottom: 1.5rem;
}

.book-list {
  display: flex;
  flex-direction: row;
  gap: 2rem;
}

.book-cover {
  width: 150px;
}

.book-title {
  font-size: 1.2rem;
}

.book-author {
  color: gray;
}
```

Apply class names in JSX using `className`:

```jsx
<div className="book-list">
  <BookApp ... />
</div>
```

## The Complete BookApp App

**`index.js`** — entry point, renders the App:

```jsx
import ReactDOM from 'react-dom/client';
import App from './BookApp.js';

const el = document.querySelector('#root');
const root = ReactDOM.createRoot(el);
root.render(<App />);
```

**`BookApp.js`** — parent component, passes props to each BookApp:

```jsx
import BookApp from './BookApp';
import MasteringReact from './mastering-react.svg';
import PracticalReact from './practical-react.svg';
import ReactInAction from './react-in-action.svg';
import './style.css';

const BookApp = () => {
  return (
    <main>
      <h1>Favourite Books</h1>
      <div className="book-list">
        <BookApp title="Mastering React"  author="Anthony Pham"  cover={MasteringReact}  />
        <BookApp title="Practical React"  author="Alex Johnson"  cover={PracticalReact}  />
        <BookApp title="React in Action"  author="Bob Climo"     cover={ReactInAction}   />
      </div>
    </main>
  );
};

export default BookApp;
```

**`Book.js`** — child component, receives and displays props:

```jsx
const Book = ({ title, cover, author }) => {
  return (
    <section className="book">
      <img src={cover} alt={title} className="book-cover" />
      <h2 className="book-title">{title}</h2>
      <p className="book-author">By {author}</p>
    </section>
  );
};

export default Book;
```

## Props — Key Rules

- Props flow **one way** — parent to child only
- Props are **read-only** — a child component must never modify the props it receives
- Any data type can be passed as a prop: strings, numbers, booleans, arrays, objects, functions, and imported assets
- String values use `"quotes"`, everything else uses `{curly braces}`
- Use destructuring in the function signature for cleaner, more readable code

---

## Summary

- **Props** are used to pass data from a parent component down to a child component.
- They make components **reusable** — the same `BookApp` component can display different books just by receiving different props.
- Props are passed like HTML attributes: `<BookApp title="React" author="John" />`
- Inside the component, props arrive as an object: `(props) => props.title` or destructured: `({ title }) => title`
- **Destructuring props** in the function signature is the preferred, cleaner approach.
- Images are imported and passed as prop values using curly braces: `cover={MasteringReact}`
- Props are **immutable** — child components cannot change the props they receive from the parent.
- Use `className` in JSX (not `class`) and import CSS files directly into the component to apply styles.
