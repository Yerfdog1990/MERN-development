# React Conditional Rendering

---

## What is Conditional Rendering?

Conditional rendering means displaying different JSX elements based on a condition — similar to how `if` statements work in JavaScript. React supports several techniques for this:

| Technique | Best used when |
|---|---|
| `if` statement | Returning completely different JSX blocks |
| Ternary operator `?:` | Choosing between two values inline |
| Logical AND `&&` | Showing something or nothing |
| Logical OR `\|\|` | Showing a fallback when a value is falsy |

---

## The Example App — Todo List

All four techniques will be demonstrated using a simple todo list. Each todo has an `id`, a `title`, and a `completed` boolean.

**`App.js`:**

```jsx
import TodoList1 from './TodoList1';

const App = () => {
  const todos = [
    { id: 1, title: 'Learn React',   completed: true  },
    { id: 2, title: 'Build an app',  completed: false },
    { id: 3, title: 'Deploy the app',completed: false },
  ];

  return (
    <main>
      <h1>Todo List</h1>
      <TodoList1 todos={todos} />
    </main>
  );
};

export default App;
```

**`TodoList1.js` (base version — no conditional rendering yet):**

```jsx
const TodoList1 = ({ todos }) => {
  const renderedTodos = todos.map((todo) => {
    return <div key={todo.id}>{todo.title}</div>;
  });

  return <section>{renderedTodos}</section>;
};

export default TodoList1;
```

Output:
```
Learn React
Build an app
Deploy the app
```

Now let's add conditional rendering to show a ✔ checkmark next to completed todos.

---

## Technique 1 — `if` Statement

Use an `if` statement inside `map()` to return completely different JSX based on a condition:

```jsx
const TodoList1 = ({ todos }) => {
  const renderedTodos = todos.map(({ id, title, completed }) => {
    if (completed) {
      return <div key={id}>✔ {title}</div>;   // completed todo
    }
    return <div key={id}>{title}</div>;        // incomplete todo
  });

  return <section>{renderedTodos}</section>;
};
```

Output:
```
✔ Learn React
Build an app
Deploy the app
```

**When to use:** When the two JSX structures are significantly different and you want to keep them clearly separated.

---

## Technique 2 — Ternary Operator `?:`

The ternary operator is a concise way to choose between two values inline inside JSX. It cannot be used with `if` statements directly inside JSX, but the ternary fits neatly inside `{}`:

```jsx
const TodoList1 = ({ todos }) => {
  const renderedTodos = todos.map(({ id, title, completed }) => {
    return (
      <div key={id}>
        {completed ? '✔' : ''}
        {title}
      </div>
    );
  });

  return <section>{renderedTodos}</section>;
};
```

The expression `{completed ? '✔' : ''}` reads as:
- If `completed` is `true` → render `'✔'`
- If `completed` is `false` → render an empty string (nothing)

**When to use:** When you need to choose between two different values or elements inline within JSX.

---

## Technique 3 — Logical AND `&&`

The logical AND operator returns the **first falsy value** or the **last truthy value**:

```js
true  && 'Show this'   // → 'Show this'
false && 'Show this'   // → false  (React renders nothing for booleans)
```

This makes `&&` ideal for showing something **or nothing**:

```jsx
const TodoList1 = ({ todos }) => {
  const renderedTodos = todos.map((todo) => {
    return (
      <div key={todo.id}>
        {todo.completed && '✔'}
        {todo.title}
      </div>
    );
  });

  return <section>{renderedTodos}</section>;
};
```

**How it works:**
- If `completed` is `true` → `true && '✔'` → returns `'✔'` (last truthy value)
- If `completed` is `false` → `false && '✔'` → returns `false` (React renders nothing for booleans)

> **Important gotcha:** If the left side evaluates to `0` instead of `false`, React **will** render `0` on screen — because `0` is a number, not a boolean. To be safe, always use an explicit boolean: `{items.length > 0 && <List />}` instead of `{items.length && <List />}`.

**When to use:** When you want to show an element or nothing at all.

---

## Technique 4 — Logical OR `||`

The logical OR operator returns the **first truthy value** or the **last falsy value**:

```js
true  || 'Fallback'   // → true
false || 'Fallback'   // → 'Fallback'
```

Use `||` to show a **fallback** value when the left side is falsy:

```jsx
const TodoList1 = ({ todos }) => {
  const renderedTodos = todos.map(({ id, title, completed }) => {
    return (
      <div key={id}>
        {completed && '✔'}
        {completed || '✖'}
        {title}
      </div>
    );
  });

  return <section>{renderedTodos}</section>;
};
```

**How `{completed || '✖'}` works:**
- If `completed` is `true` → returns `true` → React renders nothing (boolean)
- If `completed` is `false` → returns `'✖'` → React renders `✖`

Combined with `{completed && '✔'}`, the output is:

```
✔ Learn React
✖ Build an app
✖ Deploy the app
```

**When to use:** When you want to display a default/fallback value when something is empty, null, or false.

---

## All Four Techniques — Side by Side

```jsx
// 1. if statement — full JSX blocks
if (completed) {
  return <div key={id}>✔ {title}</div>;
}
return <div key={id}>{title}</div>;

// 2. Ternary — choose between two values inline
{completed ? '✔' : '✖'}

// 3. Logical AND — show or show nothing
{completed && '✔'}

// 4. Logical OR — show or show fallback
{completed || '✖'}
```

## Rendering Entire Components Conditionally

The same techniques work for conditionally rendering entire components, not just values:

```jsx
// Ternary — show one component or another
{isLoggedIn ? <Dashboard /> : <LoginPage />}

// && — show a component or nothing
{isLoading && <Spinner />}
{hasError && <ErrorMessage message={error} />}

// if statement — return entirely different JSX
if (!todos.length) {
  return <p>No todos yet. Add one above!</p>;
}
return <ul>{renderedTodos}</ul>;
```

---

## Choosing the Right Technique

| Scenario | Recommended technique |
|---|---|
| Two very different JSX structures | `if` statement |
| Two possible values or components inline | Ternary `?:` |
| Show something or show nothing | Logical AND `&&` |
| Show a fallback when value is empty/false | Logical OR `\|\|` |
| Showing a component based on a boolean flag | `&&` |

---

## Summary

- **`if` statement** — use when returning two completely different JSX blocks; keeps the logic clean and readable outside of JSX.
- **Ternary `?:`** — use inline inside JSX when choosing between two values or elements: `{condition ? 'A' : 'B'}`.
- **Logical AND `&&`** — use when you want to show an element or nothing: `{condition && <Element />}`. Avoid using `0` as the left-side value — use an explicit boolean comparison instead.
- **Logical OR `||`** — use when you want a fallback: `{value || 'Default'}`.
- All four techniques work equally well for rendering values, JSX elements, or entire components.
