# React `useEffect` Hook

### What is `useEffect`?

`useEffect` is a React Hook that allows you to perform **side effects** in functional components. Side effects are operations that reach outside the component to interact with the world, such as data fetching, manual DOM manipulations, or setting up subscriptions and timers.

Unlike state updates (which happen during rendering), side effects happen *after* the component renders.

---

### Basic Syntax

Step 1 — Import `useEffect`

```javascript
import { useEffect } from 'react';

```

Step 2 — Use the hook in your component

```javascript
useEffect(setup, dependencies);

```

| Argument | Description |
| --- | --- |
| **setup** | A function containing the side effect logic. It can optionally return a **cleanup function**. |
| **dependencies** | An optional array of values. The effect re-runs only if these values change between renders. |

---

### Standard Pattern

Typically, you write the hook with an arrow function for the setup and an optional cleanup return:

```javascript
useEffect(() => {
  // Side effect code here (e.g., API call, event listener)

  return () => {
    // Cleanup code here (e.g., remove listener, clear interval)
  };
}, [dependencies]);

```

---

### Execution Patterns

#### 1. Run Only Once (On Mount)

Pass an empty dependency array `[]`. This tells React your effect doesn't depend on any values from props or state, so it never needs to re-run.

```javascript
import React, { useEffect, useState } from 'react';

export default function UserList() {
  const [users, setUsers] = useState([]);

  const fetchUsers = async () => {
    const url = 'https://jsonplaceholder.typicode.com/users';
    const response = await fetch(url);
    const data = await response.json();
    setUsers(data);
  };

  useEffect(() => {
    fetchUsers();
  }, []);

  return (
    <div>
      <h1>User List</h1>
      <ul>
        {users.map((user) => (
          <li key={user.id}>{user.name}</li>
        ))}
      </ul>
    </div>
  );
}

```

#### 2. Run When Dependencies Change

Include values in the dependency array. The effect runs after the initial render and again whenever any value in the array changes.

```javascript
import { useState, useEffect } from 'react';

const CounterTitle = () => {
  const [count, setCount] = useState(0);

  useEffect(() => {
    document.title = `Count: ${count}`;
  }, [count]); // Runs when 'count' changes

  return (
    <div>
      <h1>Current count: {count}</h1>
      <button onClick={() => setCount(count + 1)}>Increment</button>
    </div>
  );
};
export default CounterTitle;

```

#### 3. Run After Every Render

Omit the dependency array entirely. The effect runs after every single render.

```javascript
import React, { useState, useEffect } from 'react';

const Counter = () => {
  const [count, setCount] = useState(0);

  useEffect(() => {
    console.log('Component rendered or rerendered');
  });

  return (
    <div>
      <h1>Current count: {count}</h1>
      <button onClick={() => setCount(count + 1)}>Increment</button>
    </div>
  );
};
export default Counter;

```

### Cleanup Functions

If your effect sets up a resource (like an event listener), you must clean it up to prevent memory leaks. React runs the cleanup function before unmounting the component and before the setup function re-runs.

**Example: Window Resize Listener**

```javascript
import { useState, useEffect } from 'react';

function WindowDimension() {
  const [width, setWidth] = useState(window.innerWidth);
  const [height, setHeight] = useState(window.innerHeight);

  useEffect(() => {
    const handleResize = () => {
      setWidth(window.innerWidth);
      setHeight(window.innerHeight);
    };

    window.addEventListener('resize', handleResize);

    // Cleanup function: Remove the event listener when the component unmounts
    return () => {
      window.removeEventListener('resize', handleResize);
    };
  }, []);

  return (
    <div>
      <p>
        Current dimension: {width}x{height}px
      </p>
    </div>
  );
}
export default WindowDimension;

```

### Summary Table

| Dependency Array | When does the setup run? |
| --- | --- |
| `undefined` | Every render |
| `[]` | Only once (on initial mount) |
| `[dependencies]` | On mount + whenever any value in the array changes |

* **Use `useEffect(setup)**` to run the setup function when the component renders and re-renders.
* **Use `useEffect(setup, [])**` to run the setup function once during the initial render.
* **Use `useEffect(setup, [dependencies])**` to run the setup function when the component renders and every time the items in the dependencies array change.
