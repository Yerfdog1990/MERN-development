# Axios in JavaScript 

## 1. What Is Axios?

- **Axios** is a **promise-based HTTP client** for the **browser and Node.js** — a consistent way to send async HTTP requests, handle responses, and perform network operations.
- Under the hood: browser → `XMLHttpRequest`; Node.js → the native `http` module.

### Why Axios over Fetch?

Both are promise-based, but Axios adds:

- **Request/response interception** (middleware-like hooks)
- **Streamlined error handling** (non-2xx auto-rejects; rich error object)
- **Automatic JSON transformation** (no manual `JSON.stringify`/`response.json()`)
- **XSRF protection**, **upload progress support**, **older-browser support**, built-in **timeout**

```bash
npm install axios     # or: yarn add axios / pnpm add axios
```


### The config-object form

```js
import axios from "axios";

axios({
  method: "",        // get | post | put | patch | delete ... (required in practice)
  url: "",           // endpoint (required)
  data: "",          // request body (POST/PUT/PATCH)
  headers: { },      // custom headers
  timeout: 0,        // ms; 0 = no timeout
  responseType: "",  // json (default), blob, text, stream...
});
```

All properties except `url` (and usually `method`) are optional; unset ones get defaults. Omit `method` → defaults to `GET`.

## 3. The Four Core Requests

### GET — read data

```js
axios({ method: "get", url: "api/items" });
```

### POST — send/create data

```js
axios({
  method: "post",
  url: "api/login",
  data: { firstName: "Finn", lastName: "Williams" },
  // data is auto-converted to JSON and sent as the body
});
```

### PUT — create or replace a resource at a URI

```js
const updatedItem = { name: "Updated Item", price: 150 };

axios({
  method: "put",                               // (article had a typo: "get")
  url: "https://api.example.com/items/1",      // URI identifies the exact resource
  data: updatedItem,
});
// resource exists → replaced; doesn't exist → created from the payload
```

### DELETE — remove a resource at a URI

```js
axios({
  method: "delete",
  url: "https://api.example.com/items/20",
});
```

### Shorthand methods

```js
axios.request(config);
axios.get(url[, config]);
axios.delete(url[, config]);
axios.head(url[, config]);
axios.options(url[, config]);
axios.post(url[, data[, config]]);
axios.put(url[, data[, config]]);
axios.patch(url[, data[, config]]);

// e.g. the POST above:
axios.post("/login", { firstName: "Finn", lastName: "Williams" });
```

## 4. Handling Responses

Axios returns a promise; the fulfillment value is a **response object**:

```js
{
  data: {},        // server's response body (auto-parsed JSON)
  status: 200,     // HTTP status code
  statusText: "OK",
  headers: {},     // response headers (names lowercased)
  config: {},      // the config used for the request
  request: {}      // ClientRequest (Node) / XMLHttpRequest (browser)
}
```

```js
axios.get("https://api.github.com/users/mapbox").then((response) => {
  console.log(response.data);       // { login: "mapbox", id: 600935, ... }
  console.log(response.status);     // 200
  console.log(response.statusText); // OK
  console.log(response.headers);
  console.log(response.config);
});
```

`.then()` can also take two callbacks — `(onFulfilled, onRejected)`:

```js
axios.post("/login", { firstName: "Finn" })
  .then(
    (response) => console.log(response),
    (error) => console.log(error)
  );
```

### async/await (standard practice)

```js
const fetchData = async () => {
  try {
    const response = await axios.get("https://api.github.com/users/mapbox");
    console.log(response.data);
  } catch (error) {
    console.error(error); // always wrap in try...catch
  }
};
fetchData();
```

## 5. Error Handling

- By default Axios **rejects any response outside the 2xx range**.
- Override with `validateStatus`:

```js
axios({
  baseURL: "https://jsonplaceholder.typicode.com",
  url: "/todos/1",
  method: "get",
  validateStatus: (status) => status <= 500, // only >500 rejects now
}).then((response) => console.log(response.data));
```

### Anatomy of the error object

```js
.catch((error) => {
  console.log(error.name);
  console.log(error.message);
  console.log(error.code);
  console.log(error.status);
  console.log(error.stack);
  console.log(error.config);
});
```

### The three error categories — always distinguish them

```js
axios.get("https://jsonplaceholder.typicode.com/todos").catch((error) => {
  if (error.response) {
    // 1. Request made; server responded with non-2xx status
    console.log(error.response.data);
    console.log(error.response.status);
    console.log(error.response.headers);
  } else if (error.request) {
    // 2. Request made; NO response received (network down, server unreachable)
    console.log(error.request); // XMLHttpRequest (browser) / http.ClientRequest (Node)
  } else {
    // 3. Something else broke while setting up the request
    console.log("Error", error.message);
  }
  console.log(error.config);
});
```

### Centralized error handling with interceptors

Duplicating that `.catch` per request is tedious — handle globally instead:

```js
axios.interceptors.response.use(null, (error) => {
  if (error.response) { /* non-2xx status */ }
  else if (error.request) { /* no response */ }
  else { /* setup error */ }
  return Promise.reject(error);
});
```

Production pattern — custom instance + dedicated handler (React example with toasts):

```js
// src/api.js
import axios from "axios";
import toast from "react-hot-toast";

const api = axios.create({
  baseURL: "https://jsonplaceholder.typicode.com",
});

const handleError = (error) => {
  if (error.response) {
    const messages = {
      404: "Resource not found",
      500: "Server error. Please try again later.",
    };
    const msg = messages[error.response.status] || `Unexpected error: ${error.response.status}`;
    toast.error(msg, { id: "api-error" });
    return;
  }
  if (error.request) {
    toast.error("No response from server. Check your network connection.", { id: "api-error" });
    return;
  }
  toast.error("Error setting up the request", { id: "api-error" });
};

api.interceptors.response.use(
  (response) => {
    toast.success(`${response.config.method.toUpperCase()} request successful`, { id: "api-success" });
    return response;
  },
  (error) => {
    handleError(error);
    return Promise.reject(error);
  }
);

export default api; // components import this and get error handling for free
```

## 6. Interceptors

**Interceptors** run **before a request is sent** or **after a response is received** — like middleware for HTTP. Useful for logging, auth token injection, global error handling.

- Difference from transforms: transforms only receive **data + headers**; interceptors receive the **entire config/response object**.

```js
// request interceptor
axios.interceptors.request.use((config) => {
  console.log("Request was sent");   // e.g. attach tokens, log, start spinner
  return config;
}, (error) => Promise.reject(error));

// response interceptor
axios.interceptors.response.use((response) => {
  console.log("Response was received");
  return response;
}, (error) => Promise.reject(error));
```

Write the task once — it applies to every request instead of per-call duplication.

## 7. Parallel Requests with `Promise.all`

```js
Promise.all([
  axios.get("https://api.github.com/users/mapbox"),
  axios.get("https://api.github.com/users/phantomjs"),
]).then(([user1, user2]) => {
  // runs only when ALL requests complete
  console.log("Date created:", user1.data.created_at);
  console.log("Date created:", user2.data.created_at);
});
```

Caveat: if **any** promise rejects, `Promise.all` rejects immediately with that first error (use `Promise.allSettled` when you need every result regardless).

## 8. Headers, Timeouts, and Data Transformation

### Custom headers

```js
const options = { headers: { "X-Custom-Header": "value" } };
axios.post("/save", { a: 10 }, options);
```

### Timeouts

```js
axios({
  baseURL: "https://jsonplaceholder.typicode.com",
  url: "/todos/1",
  method: "get",
  timeout: 2000, // ms; default 0 = never time out
})
  .then((r) => console.log(r.data))
  .catch((error) => {
    if (error.code === "ECONNABORTED") console.log("Request timed out");
    else console.log(error.message);
  });
```

Alternative — `AbortSignal.timeout()` (error code becomes `ERR_CANCELED`):

```js
const abortSignal = AbortSignal.timeout(200);

axios({ url: "/todos/1", baseURL: "https://jsonplaceholder.typicode.com", signal: abortSignal })
  .catch((error) => {
    if (error.code === "ERR_CANCELED" && abortSignal.aborted) console.log("Request timed out");
  });
```

### Automatic JSON transformation

```js
const data = { name: "Jane", age: 30 };
axios.post("/api/users", data); // auto-serialized to JSON + Content-Type: application/json

// pre-serialized string? set the header yourself:
const jsonData = JSON.stringify({ name: "John", age: 33 });
axios.post("/api/users", jsonData, {
  headers: { "Content-Type": "application/json" },
});
```

### transformRequest / transformResponse

Override the defaults when an API needs XML/CSV etc. (`transformRequest` works for PUT/POST/DELETE/PATCH):

```js
const options = {
  method: "post",
  url: "/login",
  data: { firstName: "Finn", lastName: "Williams" },
  transformRequest: [(data, headers) => {
    const csvData = `firstName,lastName\n${data.firstName},${data.lastName}`;
    headers["Content-Type"] = "text/csv";
    return csvData;                       // body sent as CSV
  }],
  transformResponse: [(data) => {
    const rows = data.split("\n");        // parse CSV response back to an object
    const headers = rows[0].split(",");
    const values = rows[1].split(",");
    return { [headers[0]]: values[0], [headers[1]]: values[1] };
  }],
};
axios(options);
```

## 9. Authenticated Requests

### Bearer tokens (JWT — most common in modern APIs)

```js
axios.get("/api/protected-resource", {
  headers: { Authorization: `Bearer ${token}` },
});
```

### Basic auth

```js
// manual base64 encoding:
const token = Buffer.from(`${USERNAME}:${PASSWORD}`).toString("base64");
axios.get("/api/protected-resource", {
  headers: { Authorization: `Basic ${token}` },
});

// or let Axios encode it (built-in support):
axios.get("/api/protected-resource", {
  auth: { username: USERNAME, password: PASSWORD },
});
```

> Tip: put token injection in a **request interceptor** so every call is authenticated automatically.

## 10. Progress Monitoring and Cancellation

### Upload/download progress

```js
axios.post("/api/upload", formData, {
  onUploadProgress: (progressEvent) => {
    const percent = Math.round((progressEvent.loaded * 100) / progressEvent.total);
    console.log(`Upload Progress: ${percent}%`);
  },
});
```

(For quick UI, the *Axios Progress Bar* module wires `nprogress` styling to axios automatically via `loadProgressBar()`.)

### Canceling requests — `AbortController` (current API)

```js
const controller = new AbortController();

axios.get("https://example.com/big.gif", { signal: controller.signal })
  .catch((error) => {
    if (controller.signal.aborted) console.log(controller.signal.reason);
  });

controller.abort("Request canceled."); // reason optional
```

### `CancelToken` — deprecated (legacy codebases only)

```js
const source = axios.CancelToken.source();

axios.get("/big.gif", { cancelToken: source.token }).catch((thrown) => {
  if (axios.isCancel(thrown)) console.log(thrown.message);
});

source.cancel("Request canceled.");
```

## 11. File Upload with FormData (React Example)

```jsx
import { useState } from "react";
import axios from "axios";

const FileUploadBox = () => {
  const [selectedFile, setSelectedFile] = useState(null);
  const [uploadStatus, setUploadStatus] = useState("");

  const handleFileChange = (event) => setSelectedFile(event.target.files[0]);

  const handleFileUpload = async () => {
    if (!selectedFile) {
      setUploadStatus("Please select a file first");
      return;
    }

    const formData = new FormData();
    formData.append("file", selectedFile);

    try {
      const response = await axios.post("/api/upload", formData, {
        headers: { "Content-Type": "multipart/form-data" }, // so backend (Multer) parses it
        onUploadProgress: (e) => {
          console.log(`Upload Progress: ${Math.round((e.loaded * 100) / e.total)}%`);
        },
      });
      setUploadStatus("File uploaded successfully!");
      console.log("Upload response:", response.data);
    } catch (error) {
      setUploadStatus("File upload failed");
      console.error("Upload error:", error);
    }
  };

  return (
    <div className="upload-box-container">
      <h2>File Upload</h2>
      <input type="file" onChange={handleFileChange} />
      <button onClick={handleFileUpload} disabled={!selectedFile}>Upload File</button>
      {uploadStatus && <p>{uploadStatus}</p>}
    </div>
  );
};

export default FileUploadBox;
```

> This is the frontend counterpart of a Multer-powered backend: Axios sends `multipart/form-data`, Multer parses it into `req.file`.

## 13. FAQ / Quick Revision

- **What is Axios?** Open-source promise-based HTTP client for browser + Node.js.
- **GET request?** `axios.get(url).then(...).catch(...)` — or `await` inside try/catch.
- **Why not fetch?** Auto JSON handling, interceptors, better error handling, timeouts, progress, XSRF protection.
- **Interceptors?** Middleware-like functions that modify requests before sending / responses before they reach your code — ideal for auth tokens, logging, and global error handling.
- **Response object:** `data`, `status`, `statusText`, `headers`, `config`, `request`.
- **Error triage:** `error.response` (bad status) → `error.request` (no response) → else (setup error).
- **Non-2xx rejects by default**; tune with `validateStatus`.
- **Parallel:** `Promise.all([...axios calls])`; **cancel:** `AbortController` (`CancelToken` deprecated); **timeout:** `timeout` config (`ECONNABORTED`).
- **Instances:** `axios.create({ baseURL })` for per-API defaults + interceptors.
